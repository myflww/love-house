# 爱之屋 0.10.5rc1：让记忆保留来龙去脉

本版把重点放在保存、整理和方便调用。记忆里的误解、猜想与后来变化都可以保留；爱之屋帮助大肥鱼看清来源，不替它裁决这些说法的真假。

## 这次改了什么

- **普通内容更自由地形成记忆**：有原话依据的猜想、矛盾和故事设定，可以自动整理成带说话者和语境的材料；不用为每句话逐条判断对错。重要设定、固定人格和关系变化继续保留保护与确认。
- **更正不再挡住过去**：当前问题优先使用新版本；问“当时”或“前后变化”可以一起查看旧说法、新解释和原始依据。界面新增“原话与后续变化”。
- **空闲时做实用的本地目录整理**：建立原文位置与前后文导航，这一步不调用模型、不增加 API 费用、不生成新的做梦经历或行为策略。普通模型整理仍使用用户选择的 API。
- **旧记录保留，新流程更直接**：旧反思和策略提案可以查看、拒绝或撤回，本版不再生成或接受这类提案作为新记忆。
- **旧版历史可按范围恢复**：旧版无法分清的自动更正禁用，先展示条目和来源，再一次确认开放历史读取；明确停用和真正忘记不会因此失效。
- **点开单条记忆更轻**：避免为了读一段原文复制并重新编码整库。长文和目录仍可分页，当前资料包不会被冒充为全库记忆。

继续保留个人库无固定库存上限、普通整理失败退避续排、逐渐淡忘与真实使用巩固、模型和强度选择，以及已有星云交互和更新提醒。API 凭据、余额、权限或网络故障仍需对应服务恢复；失败续排不等于能让故障服务保证成功。

## 使用时记住三件事

1. 想了解现在，正常提问即可；想看过去或变化，可以明确说“当时”“前后有什么变化”，或使用 `history` / `comparison` 读取。
2. 原文导航只列当前授权来源。断开连接会停止该连接读写，已存记忆仍由本库管理；需要退出使用或移除时，请选择停用或忘记。不同库和用户未连接的窗口不会自动混在一起。
3. 升级前备份完整数据目录。不要直接用旧程序覆盖读取升级后的数据；需要回退时同时恢复配套备份。

详细机制、三种读取示例及人类记忆论文的借鉴边界见[设计说明](memory-0105-design.md)。外部记忆整理不会训练 API 模型参数，也不声称具有人脑或参数级 SLEEP 的同等能力。

## 离线单条读取测量

本轮使用 Windows 10 19045、Python 3.13.14，仅创建合成对话，无真实用户数据、模型或网络调用。两种路径读取同一条原文，返回内容完全相同；各暖机 1 次后测量 5 次，取墙钟耗时中位数。峰值分配使用额外一次独立 `tracemalloc` 测量，是 Python 分配量，不是整个程序常驻内存。

| 合成图规模 | 原文总字符数（含助手回复） | 旧快照重建路径中位耗时 | 新图内读取中位耗时 | 旧 / 新峰值 Python 分配 |
| --- | ---: | ---: | ---: | ---: |
| 1 万节点、0 边 | 1,138,890 | 672.21 ms | 1.84 ms | 44,020,885 / 17,240 字节 |
| 5 万节点、0 边 | 5,738,890 | 3582.85 ms | 8.23 ms | 225,460,557 / 17,240 字节 |

旧路径为 `Brain(handler.memory_snapshot())` 后调用目标 `memory_read`；新路径使用真实 `MemoryHost.memory_access → scoped_memory_read → memory_read`，在现有图锁内读取同一 27 字原文。新路径同时核验不调用 snapshot，临时授权信息在成功与异常后均清除。合成资料构造见 `tests/test_memory_performance.py` 的 `synthetic_brain`；本轮原始测量见[单条读取记录](memory-0105-evidence/memory-read-benchmark.json)；另有[本地目录测量](memory-0105-evidence/source-directory-benchmark.json)。

这项测量只说明去除全图复制和重编码的收益。目标函数仍有一次与节点数相关的禁用来源扫描，表中结果不代表全部目录、语义检索、模型整理或真实用户大图都具有同样耗时。
