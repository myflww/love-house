## Windows 安装

1. 优先下载安装版 EXE，按当前用户安装。桌面包自带所需程序，无需另装 Python 或 Node。
2. 启动需要 Microsoft WebView2 Runtime 和 .NET Framework 4.6.2+。缺少 WebView2 时，程序会询问是否安装随包的微软离线组件，并核对其签名和 SHA256；该组件不包含 .NET 安装器。
3. 使用便携版时，完整解压整个文件夹，再打开 `LoveHouse.exe`。
4. 本机记忆保存在 `%LOCALAPPDATA%\LoveHouse`，与程序目录分开。请勿通过清空数据目录处理启动失败。
5. 启动异常时可运行 `LoveHouse.exe --diagnose`，按提示查看诊断；明确执行 `LoveHouse.exe --repair-runtime` 可尝试修复运行时。

本轮源码与模拟模型检查覆盖记忆纠正、来源范围、分层反馈、约定和空闲回顾。0.10.4rc1 的安装、便携、原生窗口、覆盖升级与公开下载验证尚待本轮 CI，见 [发布说明](ReleaseNotes-0.10.4rc1-Windows.md#验证记录与系统范围)。Windows 10/11 是支持目标，不表示全部系统已实测；受限安装和缺失/损坏运行时环境仍需分别验收。

## 桌面 0.10.4rc1 的整理与连接

取消每日调用、字符及待审候选总量硬上限；普通失败任务持续退避重试，旧版停住的任务会重新排队。原文保存、已有淡忘规则、候选审阅和真正忘记的选择继续保留。多个已授权窗口可同时导入与召回，每条连接仍固定记忆库及用户批准的范围。

整理模型可读取可用列表并选择推理强度；上下文与输出默认所选模型最高，未知能力由服务决定。星云普通拖动旋转，Shift 平移；悬停和空白点击继续自旋，选中节点或明确暂停才保持停止。自动检查开启时，打开软件会检查当前平台新版并弹窗提醒，下载与安装由用户选择。

本轮将经历、约定、连接状态和待核对事项集中到同一窗口，简化添加/显示入口，保留来源及错误回执。自然问法与时间线索只帮助查找已有事实。空闲回顾默认关闭，复用整理模型，只生成有证据提案；明确采纳的反思仍非用户事实，策略与模拟不自动启用，效果未验证，不训练模型参数。

步骤见 [Windows 更新与恢复说明](WINDOWS-0104-UPDATE.md)。macOS arm64 同步共享核心，但本机没有 Mac，原生构建与运行待 Apple Silicon CI；手机继续使用0.8.0rc2。源码测试不能扩展为未验证平台的兼容承诺。

## macOS 安装

下载并解压 ZIP，把“爱之屋.app”放入“应用程序”目录后打开。当前安装包仅适用于 M 系列芯片的 Mac。

macOS 包为本地签名、未公证；Windows 主程序未附发行商代码签名。请核对仓库来源和下方 SHA256，保留系统安全保护。随包微软运行时的数字签名不代表爱之屋主程序已有发行商签名。

## 手机安装

Android 下载 APK 后，按系统提示允许当前下载来源安装，再打开“爱之屋”。通用 APK 无需选择 ARM 或 x86。只使用上表的发行包；开发流水线中的 unsigned APK 和测试 APK 不用于日常安装。

iPhone 用 Safari 打开上表链接，等待页面加载完成，再点“分享 → 添加到主屏幕”。首次缓存完成后可离线使用；请从主屏幕图标进入后再保存或导入记忆。Safari 标签页与主屏幕应用可能使用不同的数据空间。

Android 和 iPhone 的真实手机兼容性仍待验收。手机本机模式可独立保存、查阅和迁移记忆；连接个人 HTTPS 记忆服务时，对应电脑或服务器需要在线。手机不会读取其他聊天 App 或电脑窗口。

如果仍在使用旧网址的主屏幕应用，先从旧应用导出 JSON，再在新入口导入。迁移完成前保留旧应用及其网站数据。更多步骤见[手机版安装与使用](手机版安装与使用.md)。

## 升级与备份

- 升级前停止写入，导出 JSON，并备份完整数据目录。桌面版回退时，应同时恢复升级前的配套数据快照。
- Windows 安装版覆盖安装；便携版完整解压到新程序目录，保留原来的数据目录。不要把程序目录当作记忆备份。
- Android 旧版用户先备份，再直接覆盖安装原签名 APK；不要先卸载。卸载后重装不属于覆盖升级。
- 卸载 Android、清除应用数据、清除网站数据或系统回收网页存储，都可能删除手机本机记忆。请定期导出 JSON。
- 设备、浏览器、Android APK 与主屏幕网页之间没有自动同步。迁移使用 JSON；Markdown 用于阅读。
