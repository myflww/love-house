# 爱之屋：产品目标与交付验收

爱之屋为每个 Agent 保存独立、可追溯、可迁移的长期记忆。聊天仍发生在用户自己的客户端；更换模型、API Key 或对话窗口，不会自动更换记忆身份。新 Agent 默认空白，人格可导入，也可依据长期互动逐步提出成长建议。

用户最新明确：记忆归属于稳定 Agent，平台、聊天窗口、浏览器和工具运行是活动来源。同一 Agent 的已登记来源汇入同一库，记录实际可观察的交流、行动与结果；不只记录 QQ 会话。详见 [Agent 身份与全活动记忆](Agent身份与全活动记忆.md)。这是统一接入目标，不能把现有聊天/工具入口说成已经覆盖所有平台的全部行为。

## 本次完整目标

1. **独立身份**：多记忆库隔离，连接固定绑定库，切换浏览中的星图不改变任何连接归属；示例单独打开。
2. **自动记录**：兼容 Chat Completions 的本地网关与已验证版本的 DeepSeek Harness 宿主插件；不依赖模型主动调用“保存”工具。记录真实用户、助手和工具角色、会话与来源，未完成回复保留档案，不伪造完整记忆。
3. **可靠保存**：先落原文档案，再入图谱；幂等去重、失败重试、暂停、断开、重启后恢复，以及明确的存档状态。
4. **模型协助整理**：可复用接入模型，也可配置独立整理 API；有界批次、调用和字符预算、任务状态、失败重试。模型提出结构化记忆，程序检查来源、归属、证据与更新边界后才保存。
5. **长期陪伴记忆**：偏好、事实、经历、约定和人格建议有来源，明确设定优先，助手自述不变成用户事实。普通信息降低召回优先级，重要记忆长期保留；记忆不是生物神经网络或模型权重训练。
6. **召回与控制**：按当前语境召回相关材料；用户可纠正、暂时停用、真正忘记，查看来源，并备份和恢复到新库。删除后的记录不能被整理任务或事件重放重新生成。
7. **轻松接入**：Harness 专用插件与其他 Agent 的复制配置是主要入口，记忆连接不要求模型厂商 API Key；整理模型和高级 API 转发独立配置。宿主检测、配置预览、应用与回滚、状态解释和自动重连均由产品承担。MCP 工具在线与宿主自动采集分开验证，未适配回调的客户端不宣称自动记录。
8. **桌面体验**：统一名称“爱之屋”，使用 imagegen 生成的像素爱心图标；简洁黑白界面、动态粒子星云和真实节点连线；支持缩放、定位、来源与折叠面板。
9. **本机交付**：测试通过后构建桌面应用，备份旧应用与数据，安装并核验。保留原 bundle ID 与 NeuralKnowledge 数据位置，避免更名导致资料分家。

## 验收证据

- 使用临时空数据目录验证首次启动、多库隔离、连接固定归属和重启持久化。
- 使用本地模拟上游模型与真实 HTTP/SSE 请求，验证网关自动记录、召回注入、幂等和中断处理；与真实付费模型调用明确区分。
- 使用独立的宿主配置和官方 Harness SessionStore 验证宿主事件；现有用户配置的变更必须有备份，并保留其他插件和凭据。
- 使用可注入整理模型验证语义计划、证据校验、预算、重试、删除防回放、更新及人工候选审阅；模型调用不持有图谱写锁。
- 验证密钥不出现在 API 响应、脑图文件、事件档案、配置、日志或导出中；钥匙串不可用时明确显示仅本次会话。
- 对可见界面做浏览器和真实桌面核验，检查空库、接入向导、整理设置、来源、折叠、主题和粒子画面。

实际完成情况及未能使用用户凭证验证的范围，在最终交付说明与验证报告中列出。没有配置用户的模型密钥时，不宣称真实模型已经联通。
