# macOS 0.10.1：独立记忆不强制连线

本版为0.10.0的小修复，macOS构建16。神经星图原绘制代码、UI、按钮、主题范围和人格形成能力均保持。Windows和手机仍使用各自发布版本。

## 孤点是正常状态

没有关联的信息可以独立保存为节点。它仍可直接检索、被Agent读取与回忆，既不要求连接数，也不会因孤立而删除。视图中的排版距离、同类颜色和装饰粒子不构成记忆关系；绘图只画实际边。

“框架示例”包含225节点、458条教学关联，其225节点累计召回计数均为0，所以平面图的高频内圈为空。原隔离视觉演示有模拟使用次数，两份样本不能混同。查看、切图、缩放和装饰光流不会增加真实调用次数；不为了填满内圈伪造调用。

## 修正的关联路径

1. 普通新增、确认记忆、承诺及历史文本导入默认不做词面猜测连边。共同叙述前缀、同一Agent名字、时间或通用标签不构成关系证据，独立保存即可。检索仍可以使用原有正文与标签，不因本次修复丢掉资料。开发者明确选择的高级auto_link仍可使用已过滤模板的内容评分；它是字面近似，不是语义证明，不能冒充默认关系。
2. 共同被召回可以巩固已有关系，不会仅因同批检索命中就给所有结果两两新增边。明确已失效的关系也不能由共同召回复活。
3. 整理模型的related_ids是提议，不能当成关系已经成立。当前版本不自动采纳这类自由提出的关联与relate，合法事实及其真实来源照常保存。实际应用阶段再次把关，旧缓存也不能绕过，且不为此追加模型请求或重置预算。
4. 用户明确的笔记引用、明确连接操作和带类型的真实事件锚点上下文保留。来源到其派生记忆的关系有实际证据，不属于为画面补线。

## 旧数据与边界

本版不擅自批量删除历史边：旧边可能来自用户手工连接、真实来源或过去的自动推断，仅凭现在的正文无法可靠分辨。升级后应用新规则；有疑问的旧关系可按来源检查后处理。弱词面相关不是已验证的现实因果，模型文本也不能给自己授予建边权限。

原始记录继续保留，关闭人格／学习等用户选择、库身份、固定连接和模型凭据均不因此改写。没有新增模型测试调用。最终完整回归929项通过（1项指定外部AstrBot环境检查跳过），桌面适配19项通过。17项独立记忆定向检查覆盖默认入口、相同叙述前缀／同鱼名／同时间、显式高级选择、共同召回、引用与旧缓存。原生WKWebView通过真实Controller新增三条共享“今天我”开头的独立主题，保存与learn=true共同召回后均0边；重启后3条原文与0边状态保留。完整包内检查及0.10.1/build16覆盖安装已完成，原库／回收站／连接范围／选库／整理设置／凭据元数据／人格选择与特征均保留。星图和UI源码与0.10.0逐字节相同，原星星与主题按钮继续原样工作。公开安装包校验见同版本发行附件。
