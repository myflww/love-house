# 爱之屋手机版安装与使用

移动预览使用独立的 `0.1.0-preview1` 版本号，不是桌面 `0.5.x` 的降级。界面与记忆保存在手机本地，不需要电脑常开。

## 按系统安装

| 手机系统 | 安装入口 | 要求与验证范围 |
|---|---|---|
| Android | [APK 下载与校验文件](https://github.com/myflww/love-house/releases/tag/android-v0.1.0-preview1) | 技术最低 Android 8.0；保持 Android System WebView 更新。一个通用 APK，无需选择 ARM / x86。预览版的具体模拟器验收记录以发布页为准，真实手机尚待验收 |
| iPhone | [打开主屏幕版](https://love-house-mobile-myflww.sharp-rice-0090.chatgpt.site) | 用 Safari 打开，分享 → 添加到主屏幕。技术最低 iOS / Safari 15.4；未完成 iPhone 真机验收 |

Android 下载名为 `LoveHouse-0.1.0-preview1-Android.apk`。在手机上打开文件，按系统提示允许当前下载来源安装，再启动“爱之屋”。它已使用持久 Android 私钥签名；同包名、同签名的后续版本可以覆盖升级。没有网络、录音、相机、通知、无障碍或广泛存储权限；只有主动导入和导出时才打开系统文件选择器。不要下载开发流水线里的 unsigned APK 或测试 APK。

iPhone 主屏幕版是离线网页应用（PWA），没有 IPA 文件，也不需要 App Store。首次联网打开、等待页面完整加载，再从主屏幕图标启动。Safari 标签页与主屏幕应用可能使用不同的数据空间，建议从主屏幕图标进入后再保存和导入正式记忆。

原生 iOS 的 Ad Hoc 安装仍需开发者签名、分发描述文件及注册设备；不能把未签名 IPA 当作任何人都能直接安装的包。参考 [Apple 分发说明](https://developer.apple.com/documentation/xcode/distributing-your-app-to-registered-devices)。Safari 15.4 的 dialog 支持见 [WebKit 发布说明](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。

## 当前功能

- 创建多个独立记忆库，记录原话、回复与标签。
- 编辑、删除、搜索当前库；查看标签关联星图。
- 导入桌面版单库分享 JSON，导出 JSON 备份与 Markdown 阅读文件。
- 关闭后保留记忆；网页应用首次缓存完成后可离线使用。

手机首版用于随身保存、查阅与迁移。它不自动读取其他聊天 App，也没有桌面 Agent / MCP / Harness 接入、模型整理、回收站或完整神经图引擎。移动星图展示共享标签关系，最多同时显示 80 个节点；全部记录仍可搜索和导出。大库列表一次展示最多 250 条，可用关键词定位其余内容。

## 与电脑迁移记忆

1. 在桌面版分享功能中导出一个记忆库的 JSON。
2. 在手机版进入“备份 → 选择 JSON 文件”，选中导出文件。
3. 导入会创建独立库，保留现有库，不执行文件中的连接、模型或密钥配置。
4. 手机上新增的原文也可导出 JSON，再用桌面分享导入功能恢复为独立库。

单个导入文件上限 32 MiB / 10,000 个节点。JSON 用于恢复，Markdown 便于阅读。不同设备、不同浏览器、Android APK 与主屏幕网页之间没有自动同步。

## 保存与备份

Android 导出会打开系统保存窗口，只有文件写入并关闭成功才显示“文件已保存”；取消选择会显示未保存。网页导出使用系统分享或浏览器下载，页面会明确提示已交给系统或已发起下载，请在“文件”或下载列表中确认。

记忆不上传到网站，网站仅提供应用文件。卸载 Android APK、清除应用数据，或清除浏览器网站数据、删除主屏幕应用、系统回收网站存储，都可能删除本机记忆。请定期导出 JSON；升级、清理手机或更换设备前先备份。相同签名的 Android 覆盖安装会保留应用数据，卸载后重装不属于覆盖升级。

## 验证记录与许可

网页已完成 360px 界面检查、真实 IndexedDB 保存、编辑与刷新恢复、独立库隔离、JSON 下载再导入。停止本地 HTTP 测试服务器后，已验证重新加载、读写和导出；这不替代 iOS 真机测试。

Android 的构建、WebView 真操作、重启持久化、库隔离和原生文件导出验证由 [构建工作流](https://github.com/myflww/love-house/actions/workflows/android.yml) 与 [最终签名包验收工作流](https://github.com/myflww/love-house/actions/workflows/android-release.yml) 执行。只有最终签名 APK 在两套模拟器通过后，发布工作流才会上传可安装文件，并提供 SHA256、证书指纹和验收 JSON。
