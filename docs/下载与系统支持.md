## Windows 安装与使用

1. 优先下载上表的安装版 EXE，按当前用户安装；不要求管理员权限。
2. 首次打开需要 Microsoft WebView2 Runtime 和 .NET Framework 4.6.2+。随包的离线组件仅用于 WebView2，不包含 .NET 安装器。WebView2 缺失时会说明并询问是否安装或修复；执行前核对固定 SHA256 与微软有效数字签名，结束后重新探测。.NET 问题会单独记录在诊断中。
3. 便携版也携带同一组件。完整解压后运行 `LoveHouse.exe`；不要只从压缩包中拖出一个 EXE。
4. 记忆位于 `%LOCALAPPDATA%\LoveHouse`，与程序安装目录分开。升级或卸载程序不应删除记忆；请勿通过清空数据目录处理启动失败。
5. 出现问题可运行 `LoveHouse.exe --diagnose`，按提示找到启动诊断；日志不包含对话原文、记忆正文或 Key。明确执行 `LoveHouse.exe --repair-runtime` 可尝试修复运行时。

旧 Windows 0.5.0 有用户启动兼容反馈，且不包含本次离线修复与新诊断。历史文件保留供追溯，新的 Windows 下载请使用上表 0.9.1rc1。

### macOS 0.10.0 的人格与整理

- 新库默认启用人格和学习，空白资料不会生成人格；用户明确关闭的选择继续保留。以上新默认与人格形成尚未移植到当前 Windows、Android 或 iPhone 版本。
- **强烈建议为当前库配置整理 API。** 在“记忆整理”设置模型与 Key，检查费用预算后按“保存并开启自动整理”；之后整理记忆时会在同一次调用中逐步补充人格。原文保存、检索、完整导出及手动设定无需模型 Key，连接 Agent 的配置仍无需模型厂商 Key。
- 导入明确标有 user／assistant 的旧聊天后，可用“快速整理人格”先预览范围、再确认最多一次模型调用。只根据可核验的助手原话归纳，不声称一次读完整库；学习结果独立展示，固定设定优先。
- 图主题只切换画布黑白，原像素界面、按钮和图标保持原配色；动态星云与平面引力图只使用已有星星按钮切换。Windows 后续同步内容见 [0.10 交接书](https://github.com/myflww/love-house/blob/v0.10.0/docs/WINDOWS-010-HANDOFF.md)。

升级前请停止写入并备份完整数据目录；本版整理数据库增加任务目的列，回退旧版时须同时恢复升级前的配套数据快照。

## 核对文件与版本

- Windows：使用同一 [0.9.1rc1 发布页的 Windows-SHA256SUMS.txt](https://github.com/myflww/love-house/releases/download/v0.9.1rc1/Windows-SHA256SUMS.txt)。
- macOS：使用同一 [0.10.1 发布页的 SHA256SUMS.txt](https://github.com/myflww/love-house/releases/download/v0.10.1/SHA256SUMS.txt)。

Windows 可在 PowerShell 使用 `Get-FileHash -Algorithm SHA256 <下载文件>`，macOS 使用 `shasum -a 256 <下载文件>`，与对应文件名的校验值逐项比对。校验文件必须与下载版本一致。

当前主程序未使用商业发行证书：macOS 为本地签名、未公证，Windows 未附发行商代码签名。请核对仓库来源与 SHA256，保留系统安全保护。随包微软运行时安装器的 Microsoft 签名与爱之屋主程序签名是两回事。

## 连接 Agent 的平台差异

Windows 使用通用 MCP 记忆连接。MCP 在线提供记忆工具，自动存档还需要宿主提交真实的轮次结束 Hook；仅复制 MCP 配置不代表自动记录已经验证。

Windows 保留 Harness 检测与实际轮次验证；WorkBuddy 使用独立 MCP 配置流程。见 [WorkBuddy 接入说明](WORKBUDDY-CONNECTION.md)。不宣称能读取任意聊天客户端。

记忆连接本身不需要模型厂商 API Key。可选的整理模型、分享阅读索引或高级 API 转发由使用者单独配置。各系统继续使用 PolyForm Noncommercial 1.0.0，保留 myflww 署名及第三方许可。

Android 0.8.0rc2 原签名安装包、iPhone 主屏幕入口与升级说明见 [手机版安装与使用](手机版安装与使用.md)。本次 Windows 同步依据另一台设备的 [0.9 交接书](https://github.com/myflww/love-house/blob/v0.9.1rc1/docs/WINDOWS-090-HANDOFF.md)，修复与验收范围见 [Windows 0.9.1rc1 说明](WINDOWS-091-FIXES.md)。
