# Windows 0.10.4rc1 更新与恢复说明

本版提供完整安装版/便携版预发布，整合七项记忆体验改进和可选空闲回顾。发行包、原生运行与覆盖升级通过本轮 Windows CI，具体范围见发布说明；资产上传和下载状态以发布页为准。

## 升级与数据保留

1. 退出爱之屋并停止向其写入的客户端，备份完整 `%LOCALAPPDATA%\LoveHouse`；自定义数据目录按实际位置备份。
2. 从 [0.10.4rc1 发布页](https://github.com/myflww/love-house/releases/tag/v0.10.4rc1) 选择完整安装版/便携版，按 `Windows-SHA256SUMS.txt` 核对相同版本、相同文件名的 SHA256。
3. 安装版覆盖原程序；便携版完整解压到新程序目录，再运行 `LoveHouse.exe`。保留原数据目录，不把程序文件放入数据目录。
4. 核对原记忆库、窗口连接、人格/学习的明确开关、整理模型与密钥状态。自动存档仍按真实宿主回调、凭据和授权窗口逐项核验。
5. 回退旧程序时同时恢复升级前的数据快照。不要通过清空数据目录处理启动问题。

## 整理、纠正与统一记忆窗口

打开“记忆整理”，确认 API、模型、强度、凭据及启用状态。个人记忆不设固定库存上限，每日调用/字符和候选累计总量不再阻塞队列；已有保留、淡忘和真正遗忘规则继续生效。

普通旧失败任务会续排，5 秒起、最长间隔 5 分钟重试，可使用“立即整理”处理积压。服务恢复后继续原进度；已完成、取消或忘记内容不重放，快速人格任务仍需明确发起。凭据、额度或网络故障需要先修复，失败数不是通过删除原文来清零。

统一记忆窗口可查看经历、约定、连接状态和待核对事项。更正时选择旧条目并填写正确事实，保存后可按原主题重验；保存、核验、图谱刷新分别显示结果。平台参与者的发言不会自动变成主人的更正。约定完成/取消只记录用户动作并保留历史，不安排消息。

模型上下文和输出默认所选模型公布的最高能力，未知能力由服务决定，也可手动设置；超窗或截断后缩片续排。每个窗口仍需明确连接到所属库和授权范围，切换浏览库不改变连接归属。

## 可选空闲回顾

在原整理面板展开“空闲回顾”。默认关闭；只读预览不调用模型，手动运行或启用后使用已有整理模型及强度。API 按实际用量计费。

回顾只生成带证据提案。低优先级反思需明确采纳，可以撤回；不成为用户事实或真实经历。策略/模拟不自动启用，当前回放效果保持未验证，不训练模型参数。撤权、修改或遗忘会使旧提案失效，生成结果不循环作为原始事实。

## 星云、更新与诊断

普通拖动旋转、Shift 平移；悬停与空白点击继续自旋，选中具体节点或明确暂停时保持停止。自动检查开启时，打开程序检查当前平台新版并提示，下载和安装由用户选择。

启动仍需 WebView2 与 .NET。可运行 `LoveHouse.exe --diagnose` 查看诊断，明确执行 `LoveHouse.exe --repair-runtime` 时按提示处理运行时。
