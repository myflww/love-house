本版包含：

- 独立存档、固定连接归属，新窗口可以延续原存档并逐页读取全部可用记忆。
- 新连接默认单窗口；本机队列前过滤、服务端复核，重启保留绑定。高级整连接范围需要用户明确允许。
- 完整对话原文无需整理模型即可召回，界面区分完整对话、工具观察、原始事件与索引等待。
- 单库完整 JSON 分享包、Markdown 阅读文件、全新库导入与可选 AI 阅读索引。
- 像素界面、神经星云、自适应视距、默认隐藏名称和按钮用途提示。

连接记忆不需要模型厂商 API Key。可选的记忆整理和阅读索引由用户自行配置模型与密钥。Harness 专用自动插件当前验证 macOS / 0.2.1-rc.3；Windows 使用通用 MCP 连接，自动存档仍需宿主真实回合结束钩子。

Windows 修复预览的干净系统 Runtime 缺失/损坏验收仍待完成，不能视为 0.5.1 正式稳定版。各系统安装步骤与接入边界见 [下载与系统支持](https://github.com/myflww/love-house/blob/main/docs/下载与系统支持.md)。
