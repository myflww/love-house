# 开源视觉来源

本项目沿用自己的知识库引擎；复用开源项目的造型、材质与通路表现。

## 采用方向：Digital Brain

- 官方仓库：https://github.com/SahilK-027/Digital-Brain
- 固定版本：`366cf81dad855ea238dec170fcc65579d6d9ba4b`
- 作者与软件许可：Sahil K，MIT，原文在 `nkb/viz/art/LICENSE.digital-brain`。
- 重点复用：`NeuralThreads.class.js` 的多频波形丝线方法、`ThreadParticles.class.js` 的沿路径粒子组织、`thread.vert.glsl / thread.frag.glsl` 的柔和亮度和颜色渐变。
- 适配：以实际节点与边替换演示生成的随机网络；真实召回trail驱动光点；节点点击、完整正文、时间预览和记忆写入继续使用本项目。
- 原仓库依赖CDN/外部素材的部分没有直接照搬；运行时使用本地固定的Three.js bundle。

原仓库Brain Areas模型另有独立许可：Versal，CC BY4.0，来源 https://skfb.ly/AFry 。本次没有把该模型当作MIT素材直接打包；所采用的神经丝线与shader部分按MIT保留归属。

上游代码快照仅在开发环境中用于复核，不随公开发布包提供；实际采用的代码保留完整署名和许可。

## 比较过的其他项目

- `vasturiano/3d-force-graph`：MIT，成熟3D图谱组件，有点击、曲线、粒子与Bloom API，适合以后作为独立空间布局底座。
- `arapr123-star/ai-brain-3d`：MIT，现成脑轮廓、星云、光晕和侧栏，但仓库提交与维护规模较小，依赖较旧CDN；本次保存只读参考与许可证，没有冒充本项目原创。
- `raultovar-space/neural-cortex`：MIT，偏真实脑区演示，原演示的神经元与连接是其数据，不应与我们的个人记忆混淆。

## Obsidian 的位置

Obsidian自带Markdown编辑、双向链接、Graph、局部Graph、Canvas等功能，适合做写入与整理入口。它的原生Graph显示笔记之间的链接；本项目的记忆状态、窗口、锚点和传播逻辑需要自己的引擎。可以后续增加Markdown/Vault适配，但本次没有迁移资料或自动安装插件。

官方能力说明：https://obsidian.md/help/Plugins/Graph%2Bview 与 https://obsidian.md/help/plugins 。
