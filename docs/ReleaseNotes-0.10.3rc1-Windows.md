# 爱之屋 0.10.3rc1 · Windows 完整发行包

本版整合记忆整理恢复、模型能力设置、多窗口并发、星云操作和启动版本提醒，提供完整安装版与便携版。保留 Windows 预览验证范围；macOS 保持已发布的 0.10.1，Android / iPhone 主屏幕版保持 0.8.0rc2。

## 记忆持续整理

反馈图中的“599650 字符 / 600000”是近24小时整理材料预算，并非记忆库容量。本版移除每日调用、每日字符及累计100条待审候选的硬上限，用量仍可查看。个人记忆的保存与逐渐淡忘继续由已有规则管理。

普通任务失败后持续退避重试，5秒起、最长间隔5分钟。旧版因尝试次数用尽而停住的任务会重新排队；已验证的计划在保存失败后复用，减少重复模型调用。混合批次中某条来源失效时，其余有效原文保留游标继续处理。模型明确超窗或输出截断时缩小分片，保留尚未处理的内容。

凭据、余额、权限或网络问题需要对应服务恢复。逐字证据、角色、记忆库归属及用户审阅保持有效；已完成、已取消或真正忘记的内容遵循原有规则。快速人格整理仍由用户明确发起，失败后不无限重复付费请求。

## 多窗口与连接鉴权

多个用户明确连接的窗口可同时导入与召回；独立写入方重放同一事件时，通过 SQLite 写事务去重。每条连接继续固定记忆库及获准窗口，浏览星图不会改变连接归属。未连接窗口、来源撤销、凭据或记忆库不匹配继续被拒绝。

验证使用真实临时 HTTP 服务、独立合成窗口与记忆库，覆盖并发、重复交付及范围校验。真实客户端仍需按其配置和回调完成一轮归档、召回核验。

## 整理模型、强度与上下文

“记忆整理”可读取服务的可用模型、推理强度与 token 上限。默认上下文及输出采用所选模型公布的最高能力；没有公布时由服务决定，也可手动填写。读取模型列表和保存设置不发送记忆正文，不调用聊天模型。

服务公布强度时按支持项选择；没有公布时提供标注“需服务支持”的通用选项。自动强度沿用服务默认，实际是否接受所选强度以 API 响应为准。连接模式使用真实连接的模型能力；换库、切换 API 或修改 Key 后，迟到响应不会覆盖当前设置，Key 不回显。

取消固定18000字符输入、4096 token输出及强制关闭思考的限制。每批只发送当前待处理材料与相关证据，按需要分片；最高上下文不会触发全库一次性发送。

## 星云交互

修复 Shift 平移后失焦、隐藏窗口或丢失指针释放时残留平移状态的问题。普通左键和笔拖动旋转，Shift 拖动平移；单指旋转，双指缩放与平移由界面统一处理。

鼠标悬停和空白点击继续自旋，拖动时跟随手势，松开后继续。选中具体节点或明确暂停时保持停止；平面模式、后台页面和减少动态效果遵循原有规则。选择、缩放和视角只影响显示，保持记忆、关系与召回次数。

## 打开时提醒新版本

自动检查开启时，每次打开请求一次当前系统的版本检查，保留服务端最短60秒去重和后台日常检查。发现新版后用原生弹窗展示当前/新版、发布说明及可信 GitHub 下载入口，支持“稍后”和“关闭”。同次运行同版本只提醒一次，已有对话框时等待。

自动检查关闭、离线、没有新版或静态 HTML 保持安静。已有发布通道选择保留，新预览版数据默认可发现预览更新。下载与安装由用户选择。
