# Bundled pixel font

Ark Pixel Font, official TakWolf release **2026.10.25**, 12px proportional, Simplified Chinese variant (`zh_hans`). The WOFF2 font is unmodified; only its container filename omits `.otf`.

- Repository: https://github.com/TakWolf/ark-pixel-font
- Fixed release: https://github.com/TakWolf/ark-pixel-font/releases/tag/2026.10.25
- Official asset: https://github.com/TakWolf/ark-pixel-font/releases/download/2026.10.25/ark-pixel-font-12px-proportional-otf.woff2-v2026.10.25.zip
- Official checksum listing: https://github.com/TakWolf/ark-pixel-font/releases/expanded_assets/2026.10.25
- Complete font license from that exact archive: `ark-pixel-OFL.txt` (SIL Open Font License 1.1).
- Exact file hashes and download provenance: `ark-pixel-source.json`.

Keep the full copyright notice and font license with distributed copies, including packaged applications. The font remains under OFL 1.1; the enclosing app's code license does not replace it. No font is sold as a standalone product here, and no font-name or glyph modifications were made.

The official project says it is still missing characters. Use an ordinary CJK system-font fallback for unsupported text. The 12px proportional face is the project's preferred width mode for normal layout; integral scaling keeps its pixel grid most apparent. Rendering and actual UI legibility still need visual QA.
