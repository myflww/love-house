# 0.10.4 记忆与使用体验整体验证

本轮在既有原文、证据、遗忘、人格与明确连接边界上改进。验证只使用隔离合成资料，模型请求使用模拟响应；真实用户数据和凭据不进入测试或发行包。

## 实施及验收

- [ ] 自然问法、时间与实体召回：换说法、指代、过去与当前事实、原文回退；无依据不编造。
- [ ] 纠正闭环：影响预览、确认事实、旧派生停用、跨窗口下一次召回验证；隐私删除不复活。
- [ ] 授权与记忆状态：连接所属库/窗口、接收/归档/整理/召回分段事实，严格区分提供与采纳。
- [ ] 共同经历与约定：由可追溯原文形成时间线、约定完成/取消后不再作为待办，保留人格证据和回滚。
- [ ] 分层使用强化：提供、可核引用、用户确认分别计权；去重、间隔及关闭后的边界保留。
- [ ] 大库性能：合成一万、五万、十万记录测量；版本化索引与缓存、写入/纠正/删除失效；无记忆容量硬上限。
- [ ] 长期质量验收：自然查询、时间更新、纠正、遗忘、多窗口鉴权与缺少证据的稳定回归。
- [ ] 全部页面与操作盘点：入口、按钮、重复操作、必要性、权限、错误/空/加载状态逐项登记。
- [ ] 简化与视觉：沿用暖色像素风格，常用/高级层级清楚，图标有名称，可用键盘；窄屏不横向溢出。
- [ ] 界面实测：每条主流程前后截图、功能验证、测试覆盖与未覆盖范围留档。
- [ ] 发布整合：完整源码与平台安装包、校验和、原生运行及公开下载复核，记录实际范围。
