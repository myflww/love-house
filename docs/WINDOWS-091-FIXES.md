# Windows 0.9.1rc1：分享导出与记忆整理修复

本次依据用户的 Windows 0.8.0rc2 反馈截图和另一台设备的 [Windows 0.9 交接书](WINDOWS-090-HANDOFF.md) 更新。Windows 提供新的修复预览；macOS 0.9.0 和 Android / iPhone 0.8.0rc2 的既有发布资产保持独立。

## 分享包按钮不可用

旧页面停在“检查这个存档的范围”，即使已勾选个人记忆确认，保存按钮仍不能使用。原因是范围预览还要读取可选整理模型的完整状态：该查询异常或等待时，会连带阻断本来无需 API 的完整导出。

现在范围预览只检查当前记忆库。AI 阅读索引的配置单独加载，其失败不会禁用完整 JSON 或 Markdown；预览失败、超时有明确提示和重试。Windows 保存等待原生桥就绪，区分取消与写入失败；库名遇到系统保留文件名时使用可保存的安全文件名。AstrBot 插件通过受控的原生保存入口导出随包源码 ZIP。

JSON 分享包包含未忘记的原文、人格和关系，可导入为独立库；Markdown 用于阅读。两者都不需要整理模型密钥。分享前仍需本人检查文件内容。

## 整理错误提示“来源已删除，未重新整理”

旧整理器先取得图快照，再领取待处理记录。两步之间新记录提交入队时，领取到的任务可能比快照更新，导致存在的原文被误判为已删除；这能在真正发出模型请求前发生，与 DeepSeek 余额或密钥是否正确无必然关系。

修复后领取任务再读取当前本库资料并复核设置；真正忘记、删除或禁用的依据仍不送去整理。旧失败记录的恢复必须重新验证当前原始资料和归档存在，不允许靠旧缓存结果复活已遗忘内容。升级后点击一次“立即整理”可恢复符合条件的旧误判任务；后台不会反复复活失败任务，原尝试次数和调用预算保留。失败状态会给出具体、安全的原因。

配置校验在写入凭据之前进行，缺模型或无效凭据不会先占用调用预算。API 密钥、余额、限流、地址或模型错误、证书、超时与无效 JSON 分开提示；不会把远端错误正文、密钥或记忆写进诊断。配置恢复只作用于本库符合条件的阻塞任务，原调用预算仍然生效。

DeepSeek 使用 OpenAI 兼容聊天接口，填写厂商基础地址及账户可用的模型。JSON 任务使用结构化响应约束，支持的官方 DeepSeek 模型关闭额外思考以保留本次有界输出预算；其他厂商或代理不会因名称相似而收到专用参数。接口说明见 [DeepSeek 调用文档](https://api-docs.deepseek.com/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/) 和 [错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。本次自动验证使用本地模拟 API，不读取用户密钥或产生真实模型费用。

## 从 0.9 交接书同步的共享功能

- 已绑定来源可保存无新用户输入的最终助手输出，保留 assistant 角色，不伪造用户消息；失败、中间步骤和未绑定窗口不能冒充完整经历。
- 整理与确认记忆独立参与召回，平台近期更正优先；来源编辑或遗忘后旧整理依据失效。来源卡仅统计实际返回材料。
- 增加“怎么连接”帮助，说明配置交给哪个运行程序、填在哪里、如何验证；登记 AstrBot 来源进入对应配置。
- AstrBot 实验插件 0.2.0、Harness 适配器 0.4.1；保留 Windows 版本发现、退出前待交排空及 WorkBuddy 的真实状态诊断。主动调度输出默认关闭。

## 下载、升级与验证范围

在 [0.9.1rc1 发布页](https://github.com/myflww/love-house/releases/tag/v0.9.1rc1) 下载 `LoveHouse-Setup-0.9.1rc1-Windows-x64.exe` 或 `LoveHouse-0.9.1rc1-Windows-x64.zip`，并用同页的 `Windows-SHA256SUMS.txt` 核对。

升级前关闭爱之屋。原数据仍位于 `%LOCALAPPDATA%\LoveHouse`；请保留数据和旧版回滚副本。分享暂不可用时，可在应用完全关闭后备份整个数据目录。便携版须完整解压。安装版按当前用户安装，主程序未附发行商代码签名。

发布验证记录包含共享回归、冻结包内后端与原生 WebView2、实际 JSON / Markdown / 插件保存、取消和错误路径、模拟模型整理，以及中文和空格路径的安装与便携检查。准确的源提交、工作流、文件散列和通过状态以同页 `Windows-091-verification.json` 为准。

要求 Windows 10 2004 / 19041 或 Windows 11 x64，Microsoft WebView2 和 .NET Framework 4.6.2+。Windows 10 新设备、缺失或损坏运行时、受限企业策略、真实用户 DeepSeek 账户以及长期运行均未被这次 CI 证明；仍标为预览。原有窗口隔离、管理鉴权、记忆、凭据作用域和非商业许可保持。
