These unmodified LICENSE.txt and NOTICE.txt files are from the official NuGet package Microsoft.Web.WebView2 1.0.3856.49. Its Microsoft copyright and BSD-3-Clause conditions are independent of pywebview’s own BSD copyright.

The five Microsoft assemblies/loaders in the verified PyPI pywebview 6.2.1 wheel byte-match members of that NuGet package. The file-by-file hashes, package URLs and validation scope are in provenance.json. No DLLs are duplicated in this source notice folder.

Copy this whole folder to the Windows bundle’s THIRD-PARTY-LICENSES directory. Check the packaged DLL bytes against provenance when building, and refresh these notices if a future pywebview release changes its SDK. Preserve NOTICE.txt, including the upstream ANTLR and StringTemplate acknowledgements.

This license covers the SDK DLLs, not the separately installed Microsoft WebView2 Runtime. Love House does not bundle or silently install that Runtime.
