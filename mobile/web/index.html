打开服务连接页

让窗口自己配置

  1. 在服务连接页生成或打开原连接，点击“复制给 Agent”。
  2. 让 Agent 保存并加载配置，调用 memory_status 和 memory_bootstrap 核对身份与存档。
  3. 宿主支持真实轮次结束回调时，再配置自动上报；完成一轮对话后查看实际记录。

仅有普通网页聊天能力的窗口，无法靠粘贴文字建立工具连接。工具已连通与已收到自动记录分别验证。

iPhone：使用 Safari 打开，点击分享，再选“添加到主屏幕”。Android：可安装 APK，或在浏览器菜单选择“安装应用 / 添加到主屏幕”。

添加到主屏幕后从图标打开，再保存和导入记忆。不同浏览器、APK 与主屏幕应用的数据可能相互独立。

本机记忆，清楚的边界

  • 本机离线库保存在当前设备；服务入口使用你自己选择的电脑或服务器存档。
  • 本机库支持手动记录、检索和文件迁移；服务连接由有 Agent 能力的窗口加载。
  • 服务配置采用通用 HTTPS MCP 与真实宿主回调；仅能打开网页不代表已自动记录。
  • 手机入口不接收模型 API Key；可选整理模型由你自己的服务管理。
