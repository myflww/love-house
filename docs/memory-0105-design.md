# 记忆可以有误解，整理应该忠于经历

适用版本：0.10.5rc1。爱之屋负责保存、整理和清楚取回已经产生的内容，供大肥鱼或其他已连接 Agent 使用。某句话确实说过，与那句话描述的事情确实为真，是两件事。

例如，先有“我以为朋友生气了”，后来有“朋友解释只是工作很忙”。两段都值得保存。后来的解释会关联到旧理解；查询现在的情况时使用新版本，问当时怎么想或前后发生什么变化时，可以一起取回两段原话。软件保留说话者、时间和来源，理解与回答仍由调用记忆的 Agent 完成。

## 保存与整理各做什么

- **原文保存**：保留实际收到的用户、助手、工具和导入材料，分清角色与来源。助手的猜测不能被改写成用户偏好，他人的发言不能自动认成主人。
- **普通整理**：把有逐字依据的内容整理成易于检索的记录。猜想、不确定说法、相互矛盾的陈述和小说设定可以形成带归属的材料，不必逐条请用户判断对错。
- **结构提取失败时**：有合法逐字证据仍可退回原句记录，不为了凑属性、主语或结论编造新内容。来源或角色本身无法核对时，保留原文和任务状态，不能伪装成整理成功。
- **受保护的变化**：覆盖用户明确确认或重要的既有设定、固定人格，以及关系状态、里程碑等变化，仍保留明确确认和已有保护规则。记录一句“我猜我们已经……”不等于替用户修改关系或确认事情已完成。

内部的 `attributed_material` 表示“某个来源确实表达过这段内容”。`certainty` 描述提取与归属是否明确，`domain` 保留现实、虚构或未知语境；它们不是软件给外部世界颁发的真假证明。普通材料自动整理也不会给模型增加执行权限。

## 三种读取方式

| 方式 | 适合的问题 | 返回重点 |
| --- | --- | --- |
| `current` 当前 | “现在的咖啡偏好是什么？” | 当前可用版本；已被更正的旧断言不再冒充当前说法，其他材料仍保留原有归属和不确定性 |
| `history` 历史 | “当时为什么会那么想？” | 可读取的旧说法、原始来源与后续记录，标明历史状态 |
| `comparison` 前后变化 | “关于这件事，前后理解有什么变化？” | 相关旧版本、新版本、原文与更正关系，便于比较变化 |

`memory_context` 可以根据“以前”“前后变化”等问法选择历史或比较模式，也可以明确传入 `view`。`memory_list`、`memory_read` 和 `memory_bootstrap` 默认使用 `current`，需要旧原文时明确指定模式。

```json
{"name":"memory_context","arguments":{"query":"朋友没有回信这件事，前后理解有什么变化？","view":"comparison"}}
```

```json
{"name":"memory_read","arguments":{"memory_id":"目录返回的实际ID","view":"history","max_chars":8000}}
```

大段原文按返回的 `next_offset` 继续读取，目录按 `next_cursor` 翻页。单次上下文有界，不代表记忆库有库存上限，也不能把一个资料包标成全库已读。目录或正文变化后，旧分页版本可能失效，需要重新读取。

界面选中记忆后可打开“原话与后续变化”，沿同一更正链查看材料。读取、浏览目录和预览不会因此修改原话或增加记忆强化次数。提供给模型的资料与模型实际采纳，仍分别记录。

## 空闲时维护本地原文目录

本版将原来的模型回顾工作改为本地目录维护，默认关闭，也可以手动运行。目录在本机整理原文的 ID、标题、角色、记录时间、来源会话、版本摘要与同会话前后位置；目录不复制一套聊天正文，不生成新的“经历”。

这一步调用整理模型 **0 次**，也不需要模型 Key。它不会编造做梦内容、建议行为策略或训练模型参数。既有的普通模型整理仍按用户选择的模型与强度运行，相关材料会发送到用户配置的 API 服务，仍可能产生费用。

维护工作按有限批次完成，提交前复核来源版本与授权；失败保留待办并重试，不把一部分完成显示成全库完成。目录读取只校验当前页及相关邻居，避免为了点开一条原文反复重建整库。

### 当前授权目录与完整记忆库的范围

`memory_directory` 是**当前授权原始来源的导航**，不是全库清单。还没建立目录、已经变化的条目、旧连接来源或不属于原始来源的整理记录，可能不在目录中；它们是否可读取，仍由记忆库自身的可用状态决定。目录未就绪时，可回退 `memory_list`，再用 `memory_read` 按需读取。

断开或撤销连接会停止该连接读写，不会隐式删除已经存入记忆库的内容。其他仍获准访问同一库的连接可以按本库规则继续读取；不同记忆库保持隔离，不会因为历史模式或目录导航而自动连接其他窗口。需要让某项已存记忆退出使用时，应明确停用；需要移除相关材料时，应使用忘记操作。

## 更正、停用与忘记分开

| 操作 | 含义 |
| --- | --- |
| 后来补充或更正 | 保存新说法并关联旧说法；旧材料仍可作为历史证据读取 |
| 明确停用 | 停止提供该记忆及受其控制的关联材料；历史模式也不能绕过 |
| 真正忘记 | 按预览范围移除原文、相关派生内容与适用的本地副本，并保持遗忘约束 |
| 逐渐淡忘 | 沿用已有连续淡化与使用巩固规则；弱化不会变成固定库存驱逐，也不等于用户要求删除 |

旧版部分自动更正使用了与手动停用相同的禁用标记，已经无法可靠区分。升级不会猜测并批量打开这些条目。若“原话与后续变化”提示旧版历史需要恢复，可以先查看精确条目和引用范围，再一次确认：恢复只开放所列历史读取，不把旧断言重新变成当前版本，不解除明确停用或忘记。预览后范围发生变化时，必须重新预览。

## 旧版反思与策略提案

本版不再生成新的模型反思、策略或模拟提案，也不再接受旧提案作为新的记忆。旧记录可以查看，待审记录可拒绝，已采纳记录可撤回；既有历史不会被无提示清空。普通内容整理与受保护设定的确认继续保留。0.10.4 的[研究记录](research/idle-review-design.md)作为历史设计保留，当前产品行为以本页为准。

## 科学依据与工程选择

以下是本次核对的人类记忆研究。实验任务、理论模型和软件系统有不同边界；它们提供设计启发，不能证明本产品具有同等的人脑机制或能力。

| 原论文及其研究范围 | 论文支持的有限结论 | 爱之屋的工程选择，属于借鉴与推断 |
| --- | --- | --- |
| Johnson、Hashtroudi、Lindsay（1993），*Source Monitoring*，来源监控理论综述；DOI `10.1037/0033-2909.114.1.3`。[作者提供的原文](https://onlineacademiccommunity.uvic.ca/lindsaylab/wp-content/uploads/sites/4861/2020/07/JohnsonHashtroudiLindsay1993_0.pdf) | 回忆涉及对信息来源的归属判断，这类判断会出错。 | 明确保留说话者、时间、来源和虚构语境，避免把“谁说过”混成“已经证真”。这不是复现人类来源判断过程。 |
| Hupbach、Gomez、Hardt、Nadel（2007），*Reconsolidation of episodic memories: A subtle reminder triggers integration of new information*，人类物品清单实验；DOI `10.1101/lm.365707`。[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC1838545/) | 在该实验条件下，提醒后学习新清单会影响稍后的旧清单回忆，出现新信息混入。 | 保留早先理解与后来补充的版本关系，避免用新摘要无痕覆盖旧原话。版本链是软件的数据设计，不是生物再巩固机制的实现。 |
| McClelland、McNaughton、O’Reilly（1995），*Why There Are Complementary Learning Systems in the Hippocampus and Neocortex*，理论与计算模型；DOI `10.1037/0033-295X.102.3.419`。[作者提供的原文](https://web.stanford.edu/~jlmcc/papers/McCMcNaughtonOReilly95.pdf) | 提出快速学习与较慢整合相互补充的解释框架。 | 将即时原文保存与后续整理、索引分开，使整理失败不影响已经保存的内容。这种分层不等于模拟海马体与新皮层。 |
| Roediger、Karpicke（2006），*Test-Enhanced Learning: Taking Memory Tests Improves Long-Term Retention*，人类文章学习实验；DOI `10.1111/j.1467-9280.2006.01693.x`。[期刊摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/) | 在该实验中，提取练习比重复学习带来更好的延迟保持，短时结果不同。 | 沿用对实际使用与后台浏览的区分；程序的淡化和巩固参数是工程近似，不是经这些实验证实的人类遗忘期限或记忆成功率。 |

我们选择忠于原文并保留认知变化，是为了让调用方看清材料，而不是让软件判定哪一种理解应成为人物唯一的“真实记忆”。本版的效果证据来自软件回归和明确条件下的性能测量，不来自对人脑能力的宣称。

## 本轮核验与性能范围

合成测试覆盖误解后解释、当前与历史对照、角色和来源、同库双窗口与独立库、停用、忘记、删源、旧版恢复、分页和来源版本变化。完整测试及两端发行包状态见[本版发布说明](release-0.10.5rc1.md)。测试没有读取真实用户记忆或调用付费模型。

单条原文读取沿用同一投影函数，把旧的“全图快照 → 重建 Brain → 读取目标”改为现有图锁内读取。离线合成图中，1 万节点从中位 672.21 ms 降到 1.84 ms，5 万节点从 3582.85 ms 降到 8.23 ms。条件与限制见发布说明；这是避免复制与重新编码的收益，不是检索索引精度或所有操作耗时的保证。
