# 爱之屋 0.10.4rc1 · Windows 完整预发布

本版整合记忆使用闭环、界面简化与可选空闲回顾，提供完整 Windows x64 安装版和便携版。本轮 CI 已独立验证构建、原生运行及覆盖升级；本版仍为预发布，实际系统范围见文末。同版本 [macOS arm64](ReleaseNotes-0.10.4rc1-macOS.md) 单独构建与验证；Android / iPhone 保持 0.8.0rc2。

## 七项记忆与使用体验改进

1. **自然问法与时间召回**：加入可审查的主题别名、近期/历史/当前和明确日期线索；无主题或无效日期保持明确提示，不生成没有原文支持的事实。
2. **纠正闭环**：有来源的更正进入待核对，由用户选择旧条目并填写正确事实；保存、按原主题重验和刷新分别回执。外部参与者发言不能自动成为主人的更正。
3. **连接状态更清楚**：显示所属库、窗口及接收、归档、整理、提供资料的实际阶段。提供过资料、回复中有逐字引用和模型真正采纳是不同结论。
4. **经历与约定集中查看**：经历、约定、连接状态和待核对事项使用同一窗口。完成/取消的约定保留历史，不再默认待跟进，不会自动发消息。
5. **分层使用反馈**：实际提供、可核对引用与用户确认分别记录；保留去重、间隔及用户关闭强化的边界。
6. **大库检索与失效处理**：改进版本化缓存，修改、纠正和遗忘后使旧索引结果失效；提供可复现的一万、五万、十万条合成资料基准，不把基准规模作为记忆容量限制。
7. **界面与长期回归**：合并显示/添加入口，高级表单默认折叠，普通记事默认经历；补齐分页、错误状态、旧响应、键盘焦点和操作清单，保持暖色像素风格。

## 持续整理与模型设置

整合 0.10.3 的修复：个人记忆不设固定库存上限，取消每日调用、字符和待审候选累计总量的硬门槛。反馈中的“字符 / 600000”曾是整理材料预算，不是记忆库容量；已有的保留、逐渐淡忘与真正遗忘规则继续生效。

普通旧失败任务重新排队，5 秒起、最长间隔 5 分钟退避重试；保留原文和处理进度。已完成、已取消或已忘记的任务不重放，快速人格任务保留明确发起边界。凭据、余额、权限或网络故障仍需对应服务恢复，不能保证故障 API 一定成功。

继续使用模型列表与推理强度选择。上下文和输出默认采用所选模型公布的最高能力，未知能力由服务决定；用户可手动设置。实际超窗或截断后分片续排，不把全库一次性发送给模型。多窗口导入与召回仍只覆盖用户明确连接的库和区域。

## 空闲回顾

位于既有“记忆整理”面板，默认关闭，复用已有整理 API、模型和强度，不增加第二套密钥。预览只读，手动运行或启用自动回顾才会调用模型。

回顾只生成带原文证据的提案。低优先级反思由用户明确采纳，可撤回；它仍是未验证的助手推测，不成为用户事实或真实经历。策略候选和模拟练习不自动启用。当前检索回放由提案自身生成探针，不是独立效果评测，界面与记录保持“效果未验证”。**外部记忆整理不训练模型参数，也不等于参数级 SLEEP。** [研究、来源和能力边界](research/idle-review-design.md)。

任务按库租约协调，提交时复核完整输入版本、窗口/来源身份与授权；撤权、纠正、删除或遗忘使旧结果失效。生成材料不作为新原始事实循环整理，失败不推进完成进度。
