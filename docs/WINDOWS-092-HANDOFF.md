# Windows 后续同步：Mac 0.9.2

本次Mac 0.9.2/build14已完成本机覆盖安装和原存档核验。Windows继续从已发布的0.9.1rc1源码及其原生安装工程开发，不用Mac目录覆盖Windows项目。

Windows 0.9.1rc1中的分享预览与整理队列修复已经作为参考合入Mac；无需再次整文件来回覆盖。继续同步时核对以下增量：

- 保留0.9的独立助手输出、整理／确认记忆独立检索、锁内索引读取、实际来源计数及原文兜底。AstrBot实验插件0.2.0与Harness适配器0.4.1的源码和分发副本保持一致。
- WorkBuddy全局配置中存在其他`love-house-memory-*`连接器时，预览及应用拒绝自动合并，提示独立配置环境或复用原连接；不读取其他连接器的私有路径，不删除其配置。保留无关MCP条目，同连接重新绑定仍可更新。
- 管理鉴权还覆盖活动来源GET和POST；无界面来源配置CLI先核验实例再建立内存UI会话。窗口策略与`bound_session_id`分开保存，重绑换发凭据并隔离旧配置、旧队列。
- 整理配置恢复保留原尝试次数和调用账本，不采用清零尝试次数的做法。旧`source_deleted`任务只在明确运行整理且来源证明、归档和遗忘检查均通过时恢复；启动或轮询不自动修复。
- 保留Mac已有严格整理引导。不能为了合并Windows共享修复而回退证据、角色和经历要求。
- 分享预览完全不调用整理器或凭据元数据。UI只有展开可选AI索引才查询状态，4秒界面超时或失败不会阻塞JSON／Markdown。只有`credential_ready`与`model_ready`均为true且用户另行同意，才允许生成索引。

Windows原生保存桥、文件名、WebView2、安装器、凭据保护与移动服务继续沿用Windows最新工程并在Windows实机验证。Mac本机构建号不能代替Windows构建号，Mac检查也不能代替Windows二进制验收。

Mac验证：854项后端回归（普通环境跳过2项另验）、19项桌面检查、指定AstrBot环境37项检查、完整包内和WKWebView原生首启／重启检查通过。新增原生情形验证可选整理状态拒绝／等待时，JSON和Markdown导出仍可用；没有真实模型调用。

请按提交差异合并并保留Windows已有修复，复测跨库、跨窗口、旧凭据、离线补交、遗忘、恢复、预算和导出。源码或安装包不包含用户数据、Key、私有连接文件或真实聊天截图。Mac安装包仅为Apple Silicon、macOS13及以上的本机签名包，未经过Developer ID公证。
