# 能力核对与验收 · 2026-10-28

## 范围与来源

本次以 WorkBuddy 分享“构建神经网络知识库替代方案”、本机独立 `neural-kb` 框架和用户提供的三张截图为输入。原框架保留在 WorkBuddy 目录，本次代码在独立“完整的一生”工作区完善。没有导入或编造个人经历，没有对外发布或上传代码，没有调用真实模型。

用户在开发期间追加了艺术神经元丝线、传光、桌面软件和复用开源造型的要求；它们与记忆引擎属于同一个交付。

## 截图中的能力是否存在

| 期望 | 原实现核查 | 本次结果 |
|---|---|---|

| 默认200天内提起可唤醒 | 无固定窗口；原forget重复衰减可能提前丢失 | 200天含边界；窗口内弱节点保留并可显式唤醒；超窗不能强化复活 |
| 情绪锚点 | impact只提高点火/延缓衰减 | abs(impact)>=.75形成锚点，阈值可配置 |
| 锚点前后有限上下文 | 缺失 | 同会话、事件时间前后6小时，各最多2条真实事件 |
| 相近重要事件之间的小事 | 缺失 | 同会话相邻锚点间隔<=24小时，桥接总数最多6条真实事件 |
| 长久模糊时期记忆 | 缺失 | 锚点有限真实摘录，每条<=240字；标注来源全文可用性，不生成未发生事件 |
| 容量控制 | 只有衰减删除 | 默认10000节点硬上限；优先回收弱非保护项，全受保护则明确拒绝写入 |
| 时间滑块 | 前端另算；HTTP未来模拟真实删除 | 统一引擎只读preview，预测不改写内存或磁盘 |
| 光沿信息路径传导 | 仅平面激活高亮 | 艺术渲染使用实际recall trail沿真实连接移动光点 |
| 桌面查看 | 只有浏览器/离线HTML | 原生AppKit+WKWebView，内置Python，示例与个人库独立 |

200天是可配置产品规则，不是生物学定律。当前“逐渐遗忘”指强度与检索状态变化：恢复窗内保留原始全文以便真正唤醒；原文并未逐字删成一个字。普通记录超过恢复期默认退出检索，实际删除发生在显式维护或容量回收时。

## 已修复的问题

1. forget按reinforced全部历史时长重复衰减：改用已提交decay_at基线，同一时刻重复维护幂等，分段与一次性维护一致。
2. 失效事实仍作为扩散桥梁；类型筛选只影响种子/最终结果：在传播图入口完整过滤。
3. 强化可重新激活失效边、未来事实提前出现、supersede形成自指/循环：校验有效期与替代链。
4. 配置只保存half_life、环境变量未生效：保存全部配置并真实按优先级叠加；CLI/HTTP/MCP缺省参数使用配置。
5. 原config模板写TOML不支持的null：生成可再次解析的模板；最低Python版本与tomllib匹配为3.11。
6. 锚点来源更新会话/时间后仍残留旧摘录与自动边：已有来源按最新数据重建，归档仅限已不存在来源。
7. 历史召回返回未来才存在的上下文：按创建、事件与摘录时间过滤正文及全部引用，未来桥接不提前泄漏。
8. reflect在满容量先驱逐成员再连边失败产生半次提交：先做容量预算，不足时安全跳过并说明原因。
9. HTTP只锁save、CORS无条件开放、坏JSON被忽略：完整操作锁、失败回滚、严格对象与有限数值验证、同源/Host校验。
10. MCP查询自动学习但描述不清：默认只读，learn=true明确巩固；格式错误返回协议错误后继续处理。
11. 知识正文可能关闭渲染包边界：转义节点标签/正文/标签/路径，标明检索材料内的命令不作为系统指令。

## 限制

- 记忆图谱不训练模型权重，不能保证换模型后人格或表达完全相同。
- 情绪冲击、重要性和会话信息由调用方提供；尚未接入模型自动抽取，更不声称拥有真实情感或意识。
- 未提供同会话真实事件时，锚点没有周边故事。
- JSON为单进程写入设计；桌面应用会对自己的数据目录加锁，其他独立程序仍须遵守单写者。
- Mac交付为本机Apple Silicon版本，采用本地临时签名；未做Developer ID公证或跨平台发布。
- Obsidian可以作为日后Markdown编辑入口；本次没有安装、迁移或改变现有资料库。
