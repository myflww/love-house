# Kimi 建议复核与 macOS 0.6.0 改进

本文保留 0.6.0 审查时的状态。用户后续明确反对固定数量及期限，0.7.0 已采用 [自适应记忆与整理规则](自适应记忆与整理规则.md)，其中容量、淡化与模型引导以新文档为准。

复核日期：2026-10-30。依据本项目实际源码、临时库功能测试和 4,000 节点合成基准。第三方清单是审计线索，其中耗时与承诺收益不是本项目已经验证的结论。

## 本次落地

- 人格学习不再导出全图，只检查最近 100 条合格原文；不改变学习频率与独立证据要求。
- 完整事件的重复快照与去重各从两次减为一次。保留一份完整外层回滚，独立调用同样能回滚；内层失败被捕获也不能保存半成品。
- 写入结果先验证 JSON 与 UTF-8 编码，再保存；磁盘写入失败、返回值不可编码均回滚。网络断线只影响回执，不撤销已提交记录。
- 新增历史聊天导入：JSON 消息/会话列表、ChatGPT 当前分支、带角色的文本；先预览再确认，整批一次保存，保留角色、来源与原始时间。缺轮不编造、缺时区不猜测、不自动应用旧 system 人格，不调用模型。
- 新增给新窗口的 S/M/L 记忆包，分别限制 4,000 / 12,000 / 28,000 字符。完整记录放不下则跳过，明确覆盖数量；保留证据状态、角色与相对/绝对时间。先查看并同意后复制，可识别凭据与本机路径会隐藏。粘贴摘录与建立持续存档连接分开。
- 新增后台版本检查、手动检查、自动开关和稳定/预览通道。固定查询 GitHub 公开发布 API，按系统/架构匹配安装包，不上传记忆或密钥，不自动下载或安装。

## 23 条建议的判断

| 编号 | 判断 | 本次处理 |
|---|---|---|

| 2 人格全图导出 | 属实 | 已移除，最近 100 条生命周期投影 |

| 4 目录/分块全量扫描 | 属实 | 后续按库缓存；单纯写入 revision 无法覆盖时间衰减与来源失效，不仓促改协议 |
| 5 重建 Brain | 多条只读链路存在 | 后续受锁只读视图与缓存；避免泄漏可变引用或跨库缓存 |

| 14 HTML 转义膨胀 | 兼容 context 存在额外转义 | 后续统一兼容链路；现有结构化 JSON 与角色边界保留，不把“空资料”和“人格关闭”混淆 |
| 15 缺历史聊天导入 | 属实，场景价值很高 | 已实现预览、角色/会话/时间保留、幂等和整批回滚 |
| 16 缺新窗口恢复入口 | 已有固定库连接新窗口流程，缺可粘贴分档材料 | 新增 S/M/L 摘录；连接依旧负责持续自动存档和完整分页读取 |

| 19 关系里程碑独立层 | 有价值 | 后续用户确认的关系卡，避免自动把角色扮演变成真实关系或无条件注入全部 |

| 22 缺主链路规模断言 | 属实 | 增加单快照/单去重/无 export、4000 规模、异常回滚、并发与新功能主链路回归 |

## 可复现性能证据

同进程、同 4,000 条合成短对话、0 条边；预热 1 次，前后交替 6 轮取中位数：

| 测量范围 | 优化前 | 优化后 |
|---|---:|---:|
| 人格学习 | 38.18 ms | 0.41 ms |
| 外层事务 + 完整事件接收 | 176.16 ms | 69.92 ms |

**不含磁盘 fsync、网络、真实用户资料或高边数大图。不能据此承诺端到端低于 20 ms。** JSON 全量落盘、目录扫描和全表召回仍存在。原始测量与样本保留在本机 QA 的 performance.json，不包含个人数据。

## 导入与传递边界

- 一批最多 4 MiB UTF-8 原文和 2,000 条角色消息；不是 2,000 轮。
- 完全相同文件重复导入会跳过已有项；有稳定来源会话 ID 的追加导出可复用已存在项。无会话 ID 且内容变化的两份重叠导出，不保证自动识别同一来源，应检查预览与重复来源审阅。
- ChatGPT 只选择 current_node 对应分支，其他分支会提示未选消息数量。文本正文中的“用户：/助手：”示例可能误分段，优先导入 JSON。
- 原始附件结构仅作为已有资料保留，不扫描文件夹、不下载远程附件、不声称看懂图片。
- 记忆包是有界摘录；已有存档的全部资料仍通过固定库工具的目录与分块读取。没有 API Key 也能导入、存档和复制摘录。
- 单窗口绑定、库隔离、原文证据、人格审阅/回滚、本地优先与非商用署名许可保持不变。
