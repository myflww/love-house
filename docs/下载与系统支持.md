## Windows 安装与使用

1. 优先下载上表的安装版 EXE，按当前用户安装；不要求管理员权限。
2. 首次打开需要 Microsoft WebView2 Runtime 和 .NET Framework 4.6.2+。随包的离线组件仅用于 WebView2，不包含 .NET 安装器。WebView2 缺失时会说明并询问是否安装或修复；执行前核对固定 SHA256 与微软有效数字签名，结束后重新探测。.NET 问题会单独记录在诊断中。
3. 便携版也携带同一组件。完整解压后运行 `LoveHouse.exe`；不要只从压缩包中拖出一个 EXE。
4. 记忆位于 `%LOCALAPPDATA%\LoveHouse`，与程序安装目录分开。升级或卸载程序不应删除记忆；请勿通过清空数据目录处理启动失败。
5. 出现问题可运行 `LoveHouse.exe --diagnose`，按提示找到启动诊断；日志不包含对话原文、记忆正文或 Key。明确执行 `LoveHouse.exe --repair-runtime` 可尝试修复运行时。

旧 Windows 0.5.0 有用户启动兼容反馈，且不包含本次离线修复与新诊断。历史文件保留供追溯，新的 Windows 下载请使用上表 0.5.1rc1。

## 验证范围

Windows 修复预览已完成 Windows 11 x64 本机普通窗口、非管理员安装、中文与空格路径、重复启动、分享导入、重启、MCP 与 Hook 验证。GitHub Windows 构建还验证安装版和便携版在没有开发环境 PATH、存在 Python/CLR/WebView2 环境污染时的启动。

公开发布流程会从真正的公开下载地址重新获取 EXE、ZIP 和校验文件，再核对 SHA256、安装、解压并运行后端与原生界面检查；检查同时要求退出码 0、`ok: true` 和 `process_complete: true`。公开下载验收结果见 [发布工作流](https://github.com/myflww/love-house/actions/workflows/release.yml)。

当前仍缺少干净 Windows 10/11 上 Runtime 缺失、实际损坏及受限安装策略的完整实测，因此此版明确标为 **修复预览**，不是 0.5.1 正式稳定版。预装 Runtime 的 CI、模拟测试和一次启动成功都不代表所有电脑已验收。

macOS 0.5.0 保留现有稳定包，不将 Windows 修复当作 Mac 更新。两端没有自动云同步。

## 核对文件与版本

- Windows：使用同一 [0.5.1rc1 发布页的 Windows-SHA256SUMS.txt](https://github.com/myflww/love-house/releases/download/v0.5.1rc1/Windows-SHA256SUMS.txt)。
- macOS：使用同一 [0.5.0 发布页的 SHA256SUMS.txt](https://github.com/myflww/love-house/releases/download/v0.5.0/SHA256SUMS.txt)。

Windows 可在 PowerShell 使用 `Get-FileHash -Algorithm SHA256 <下载文件>`，macOS 使用 `shasum -a 256 <下载文件>`，与对应文件名的校验值逐项比对。校验文件必须与下载版本一致。

当前主程序未使用商业发行证书：macOS 为本地签名、未公证，Windows 未附发行商代码签名。请核对仓库来源与 SHA256，保留系统安全保护。随包微软运行时安装器的 Microsoft 签名与爱之屋主程序签名是两回事。

## 连接 Agent 的平台差异

Windows 使用通用 MCP 记忆连接。MCP 在线提供记忆工具，自动存档还需要宿主提交真实的轮次结束 Hook；仅复制 MCP 配置不代表自动记录已经验证。

Harness 专用自动配置向导目前仅有 macOS / `0.2.1-rc.3` 的明确验证。Windows 不宣称支持该自动向导，也不宣称能读取任意聊天客户端。

记忆连接本身不需要模型厂商 API Key。可选的整理模型、分享阅读索引或高级 API 转发由使用者单独配置。各系统继续使用 PolyForm Noncommercial 1.0.0，保留 myflww 署名及第三方许可。
