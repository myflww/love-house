# 爱之屋 0.10.2rc1 · Windows AstrBot 接入与状态更新

本版基于 Windows 0.10.1rc1，新增 AstrBot 快速配置、当前记忆库整理 API 状态和动态星云自旋。Windows x64 安装版与便携版使用同一批源码。macOS 本次提供移植交接书，尚未构建新版；Android 保持现有版本。

## AstrBot 快速接入

选好记忆库，打开“同鱼活动来源”，选择 AstrBot，确认它与爱之屋服务位于同一机器、共享文件系统。到目标 AstrBot 会话发送 `/sid`，将返回的 UMO 粘贴到向导，选择平台并确认归属后生成配置。

向导自动对齐私有来源配置路径、插件固定标识和会话白名单，给出可复制的完整插件 JSON、固定文件位置及安装、重载步骤。导出 0.3.0 实验插件，安装到 AstrBot 的 `data/plugins/astrbot_plugin_love_house`；首次安装可使用生成的配置，已有多条绑定应合并 `bindings`，不要覆盖其他鱼的配置。

随后在 AstrBot 面板重载插件，在目标会话发一轮真实对话，再核对来源上报和记忆入库。“已生成配置”不代表插件已加载或真实对话已入库。另一台服务器或隔离容器不能直接读取本机私有路径，向导会说明这项限制。

插件逐条隔离无效绑定，保留有效绑定；冲突会话不猜归属。状态命令报告拒收原因计数，不暴露会话标识、原文和凭证。持久交接后清除本地正文的状态有明确名称，并兼容旧记录。

## 当前库的整理 API 状态

库名下常驻显示“未配置”“已配置”“仅本次运行”“密钥不可用”等状态，点击可打开整理设置。整理面板直接展示服务、模型、凭据保存方式；换库时立即清空旧状态，保存失败不会显示配置成功。

保存和查看状态不会发起模型请求；“已配置”表示本机配置已保存，不代表厂商已接受密钥。最近实际调用失败时会另外提示。完整 JSON／Markdown 导出仍无需整理 API。

## 星云缓慢左转

动态星云自然状态下水平从右往左缓转，约三分钟一圈；鼠标进入画布后暂停，移开后从当前角度继续。拖拽、手动暂停、平面模式、后台页面及系统“减少动态效果”会停止自旋。旋转只改变观看角度，不修改记忆坐标、关系和召回次数。

## 下载、升级与验证

Windows 包与验证附件见 [本版发布页](https://github.com/myflww/love-house/releases/tag/v0.10.2rc1)，详细步骤见 [Windows 更新说明](https://github.com/myflww/love-house/blob/v0.10.2rc1/docs/WINDOWS-0102-UPDATE.md)。

升级前停止写入并备份完整数据目录。便携版应完整解压到新程序目录；保留原来的数据目录。原有库隔离、人格明确关闭设置、来源绑定和记忆原文应继续保留。

发布流程要求完整回归、实际原生窗口、安装／便携运行检查和 0.10.1rc1 覆盖升级全部通过；完成记录以 `Windows-0102-verification.json` 及发布页链接为准。公开后另从匿名下载链接重新安装和启动，证据单独记录。测试使用合成资料、模拟 API，不读取真实用户密钥，不代发 QQ 消息。Win10 真机、真实 QQ 长期运行和各厂商真实账户仍需独立验收。
