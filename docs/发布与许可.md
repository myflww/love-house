## 发布范围

公开仓库只包含运行和开发需要的源代码、批准的界面素材、测试、示例和第三方许可。不会上传开发者的聊天记忆、导出分享包、连接令牌、模型 Key、系统钥匙串、回滚副本、验收截屏或本机报告。

准备干净的源码目录：

```bash
python3 scripts/prepare_public_release.py --output dist/public/love-house
python3 scripts/prepare_public_release.py --scan dist/public/love-house
```

脚本按允许清单复制文件，在复制前检查疑似凭据、本机用户路径、私有记忆文件和符号链接。发现问题时只报告文件、行号和类别，不输出匹配到的秘密。它不会联网、创建仓库、上传文件、读取钥匙串或读取用户应用数据目录。目标目录必须不存在，避免把旧发布文件混入新版本。

`PUBLIC_SOURCE_MANIFEST.json` 记录每个实际发布文件的相对路径、大小与 SHA-256。发布前应在该干净目录运行测试并核对版本；桌面 ZIP 另外检查签名、依赖许可、启动功能与不包含预置个人记忆。脚本的确定性检测不能判断任何任意字符串是不是秘密，人工确认发布清单仍是发布者的责任。

独立记忆分享文件由用户在软件里选择一个存档后导出。**公开发布项目代码不包含用户的分享文件**。这些文件可能包含双方原话、偏好和经历，应由用户自行决定分享给谁。

## Windows 安装包中的第三方材料

Windows 原生窗口使用 pywebview、Python.NET、clr-loader 与微软 WebView2 SDK，程序由 PyInstaller 打包、Inno Setup 制作安装器。它们各自的原始许可与作者归属见 `THIRD_PARTY_NOTICES.md`，实际构建中的 wheel 许可及版本记录随包放在 `THIRD-PARTY-LICENSES/`。PyInstaller 的 bootloader 例外允许打包后的应用采用自己的许可，不要求把爱之屋的代码改为 GPL；修改并再分发 PyInstaller 本体则仍须遵守它的原始许可。

pywebview 6.2.1 包含的微软 SDK DLL 已按字节匹配到官方 NuGet **Microsoft.Web.WebView2 1.0.3856.49**。对应 SDK 的完整 `LICENSE.txt`（BSD-3-Clause）和 `NOTICE.txt` 必须随 Windows 包保存，不能用 pywebview 自己的 BSD 许可代替微软的署名与第三方通知。此 SDK 与独立的 **WebView2 Runtime** 是两种材料，Runtime 继续遵守微软自身条款，不改为 BSD。

旧 Windows 0.5.0 不携带 Runtime，缺失时需要另行安装。Windows 0.5.1rc1 修复预览开始随包提供经过固定 SHA256 和 Microsoft 有效数字签名验证的 Evergreen x64 离线安装组件，缺失时向使用者说明并询问后执行，结束后重新探测；便携版提供明确修复入口。微软分发依据见 [WebView2 Runtime 分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。各系统版本、公开下载入口及真实验收范围见 [下载与系统支持](下载与系统支持.md)。macOS 0.5.0 稳定包继续保留。

Windows 发布应以实际 Windows runner 完成的原生窗口、安装后启动、记忆隔离与 MCP 测试结果为准。Mac 上通过源码/许可检查不等于 Windows 二进制已验收。更换依赖版本或 SDK 字节时，需要同步更新许可证清单与相应源码来源。
