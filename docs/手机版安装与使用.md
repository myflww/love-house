# 爱之屋 Android 安装与使用

**当前公开 APK 为 `0.8.0rc2`；新版 `0.10.6rc1` 已完成构建和本机模拟器验收，等待原签名和覆盖升级验收，尚未提供新的发行 APK。** 本页区分已发布旧版与新版完整引擎，具体实施和验证进度见 [Android 0.10.6 更新说明](ANDROID-0106-UPDATE.md)。

## Android 安装

| 手机系统 | 安装入口 | 要求与验证范围 |
|---|---|---|
| Android 已发布版 | [0.8.0rc2 APK 与校验文件](https://github.com/myflww/love-house/releases/tag/v0.8.0rc2) | 技术最低 Android 8.0；保持 Android System WebView 更新。旧版通用 APK 无需选择 ARM / x86。预览版的模拟器验收记录以发布页为准，真实手机尚待验收 |

上表旧版文件名为 `LoveHouse-0.8.0rc2-Android.apk`。在手机上打开文件，按系统提示允许当前下载来源安装，再启动“爱之屋”。旧版仅有本机离线视图，个人 HTTPS 服务通过系统浏览器打开，没有新版内置 Python 引擎。

新版目标为 Android 8.0+、WebView 109+、64 位 ARM / x86 设备；新增网络权限，用于本机引擎、模型 API 与更新检查。它不会读取其他 App，主动导入和导出仍使用系统文件选择器。新版完成原发行私钥签名与验收后，才会替换本页下载。旧版用户先逐库导出 JSON，再直接覆盖安装，不要先卸载。不要安装开发流水线中的 unsigned APK 或测试 APK，也不要将其改名当作新版发行包。

项目已停止提供 iPhone 版，不再提供其安装入口或后续更新。已有用户请按下方[旧 iPhone 版的记忆迁移](#旧-iphone-版的记忆迁移)导出原有资料。

## 新版完整记忆：0.10.6rc1 待原签名

进入旧版离线入口后，新版提供“打开完整记忆”和“迁移当前旧库”。完整记忆在手机本机运行与桌面相同版本的核心，使用适配手机的完整管理页面，接入整理、人格、召回、更正历史、独立库和神经星图。模型整理需在目标库配置 API 服务，费用由所选服务按实际使用量收取；保存原文和已有记忆检索不需要整理 Key。

需要迁移时先选择旧库、导出备份，再明确点击“迁移当前旧库”并确认。只通过脱敏分享格式导入该库，原库不会删除；新旧数据区不会自动双向同步。导入后请核对原文、回复和数量。完整步骤见 [新版更新说明](ANDROID-0106-UPDATE.md#旧库如何进入完整记忆)。

手机本机引擎监听 `127.0.0.1`，只指这台手机。连接代码交给实际运行 Agent 的宿主；电脑或云服务器上的 Agent 应连接其所在设备的爱之屋服务，手机再通过它的 HTTPS 管理入口查看。不要把手机的 `127.0.0.1` 当作远端服务器地址。

自动存档依赖宿主持续上报真实对话和事件。关闭完整记忆界面、系统省电或结束应用进程会影响手机接收，不承诺全天后台记录。需要全天运行的鱼，建议在电脑或服务器持续运行爱之屋。再次打开可继续使用已保存的本机记忆，离线时未投递的记录能否补送取决于宿主队列。

## 已发布旧版：0.8.0rc2

- 创建多个独立记忆库，记录原话、回复与标签。
- 编辑、删除、搜索当前库；查看标签关联星图。
- 导入桌面版单库分享 JSON，导出 JSON 备份与 Markdown 阅读文件。
- 关闭后保留记忆，本机记录无需连接服务即可使用。

手机本机模式用于随身保存、查阅与迁移。连接个人 HTTPS 服务后，可在浏览器管理 Agent 连接、查看绑定和接收状态，确认后重新绑定窗口；电脑上 WorkBuddy 的配置仍由那台电脑完成。MCP 在线与收到一次事件都不代表持续自动存档，详见 [WorkBuddy 接入说明](WORKBUDDY-CONNECTION.md)。手机不会读取其他聊天 App 或电脑窗口。移动星图展示共享标签关系，最多同时显示 80 个节点；全部记录仍可搜索和导出。大库列表一次展示最多 250 条，可用关键词定位其余内容。

## 与电脑迁移记忆

1. 在桌面版分享功能中导出一个记忆库的 JSON。
2. 新版 Android 先打开“完整记忆”，在其分享/导入页面选择 JSON；不要把新版全量库导入旧版离线入口。旧离线视图不支持新版的全部配置，例如时间保留模式的 `max_nodes:null`。
3. 导入会创建独立库，保留现有库，不执行文件中的连接、模型或密钥配置。
4. 手机上新增的原文也可导出 JSON，再用桌面分享导入功能恢复为独立库。

旧版离线入口的单个导入文件上限为 32 MiB / 10,000 个节点；“迁移当前旧库”也受原离线导出单包 32 MiB 限制，超过时保留原库并报告错误。新版完整引擎的导入按其预览和文件校验处理，旧视图的单次导入限制不代表完整记忆库的库存上限。JSON 用于恢复，Markdown 便于阅读。不同设备之间没有自动同步。

## 保存与备份

已发布的旧版导出会打开系统保存窗口，只有文件写入并关闭成功才显示“文件已保存”；取消选择会显示未保存。新版完整引擎的文件导出也须经过实际原生验收后记录结果。请在系统“文件”应用中确认备份文件能够打开。

卸载 Android APK 或清除应用数据会删除本机记忆。请定期导出 JSON；升级、清理手机或更换设备前先备份。相同签名的 Android 覆盖安装会保留应用数据，卸载后重装不属于覆盖升级。

## 旧 iPhone 版的记忆迁移

旧主屏幕版的记忆仍在原设备、原应用或原网站的数据空间中；停止提供此版本不会自动把记忆移到其他设备。无需重新安装旧版，先打开原来一直使用的主屏幕应用：

1. 进入“备份”，逐个选择记忆库并导出 **JSON**。在系统“文件”中确认文件已实际保存；Markdown 只能用于阅读，不能代替 JSON 备份。
2. 将 JSON 通过自己选择的方式传到 Android 或电脑，在爱之屋中导入。每次导入创建独立库，不会替换目标设备原有的库。
3. 核对库名、原文、回复和记录数量，确认备份与导入结果后，再决定是否删除旧应用。

迁移完成前不要删除主屏幕应用或清除 Safari 网站数据，也不要指望换网址、重装或更新系统自动找回本机存档。Safari 标签页和主屏幕应用可能使用不同的数据空间；应从保存过记忆的那个入口导出。已无法打开旧应用时，保留原设备及其网站数据，不要先执行清理。

## 验证记录与许可

已发布旧版的本机视图已完成 360px 界面检查、真实 IndexedDB 保存、编辑与刷新恢复、独立库隔离、JSON 下载再导入。停止本地 HTTP 测试服务器后，已验证重新加载、读写和导出；这些旧证据不能代替新版完整引擎、原签名升级或真实手机验收。

0.8.0rc2 的旧版验证由 [构建工作流](https://github.com/myflww/love-house/actions/workflows/android.yml) 与 [原签名升级验收工作流](https://github.com/myflww/love-house/actions/workflows/android-original-signing-080rc2.yml) 记录，包含 Android 9 / Android 16 模拟器从 `0.1.0-preview1` 和 `0.8.0rc1` 覆盖升级，以及 WebView、持久化、独立库与系统文件导出检查。新版 0.10.6rc1 需要另行验收并记录从已公开 0.8.0rc2 升级的结果、最终 APK SHA-256 和证书指纹，不能直接沿用旧版通过结论。
