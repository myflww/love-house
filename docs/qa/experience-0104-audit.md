## 证据层级与覆盖边界

- 静态盘点覆盖主模板、动态操作族和原生菜单。没有因为按钮名称相近就删除不同的导入、恢复或隐私功能。
- DOM 回归覆盖显示/添加菜单、导航、焦点、全部生产详情分组、经历与约定、更正回执、回顾分页、跨库/关闭后的迟到响应。它不等于每个像素状态都被人工点击。
- 本机真实 HTTP 测试覆盖授权、多个窗口写入和取回、独立库隔离、外部参与者本人确认、凭据失效、删除闭包、备份/回收站恢复后的重新同意。预览不会强化记忆。
- 浏览器真实操作覆盖宽窄窗口、显示菜单、连接状态、经历/约定、添加校验和保存、更正与独立核验、可恢复停用、只读回顾预览。永久删除最终动作通过隔离 API 回归验证，界面只检查范围预览和取消。
- Windows/macOS 冻结应用的实际构建、启动、共享可见控件探针和升级结果，以本轮发布附带的新报告为准。平台不适用项的 skip 不作为实际兼容性通过。

截图保存于本轮隔离验收产物的 baseline/after 目录，不进入公开源码包。主要改后证据：01 导航、02–03 窄屏菜单、04 连接阶段、05 已完成约定、06 详情、07 回顾预览、08 更正独立核验。

## 尚未证明的能力

本轮没有进行真实提供商的独立留出任务效果评测；回顾提案的 effectiveness 始终为 unverified。检索回放可以检查选择和窗口边界，不能证明模型推理能力提高、真实采用记忆或模型参数发生变化。十万条稀疏短文本基准仅反映该合成条件，仍有线性扫描和完整存档成本，不能据此承诺所有十万条真实资料都即时响应。
