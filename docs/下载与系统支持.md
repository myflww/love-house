## Windows 安装与使用

1. 优先下载上表的安装版 EXE，按当前用户安装；不要求管理员权限。
2. 首次打开需要 Microsoft WebView2 Runtime 和 .NET Framework 4.6.2+。随包的离线组件仅用于 WebView2，不包含 .NET 安装器。WebView2 缺失时会说明并询问是否安装或修复；执行前核对固定 SHA256 与微软有效数字签名，结束后重新探测。.NET 问题会单独记录在诊断中。
3. 便携版也携带同一组件。完整解压后运行 `LoveHouse.exe`；不要只从压缩包中拖出一个 EXE。
4. 记忆位于 `%LOCALAPPDATA%\LoveHouse`，与程序安装目录分开。升级或卸载程序不应删除记忆；请勿通过清空数据目录处理启动失败。
5. 出现问题可运行 `LoveHouse.exe --diagnose`，按提示找到启动诊断；日志不包含对话原文、记忆正文或 Key。明确执行 `LoveHouse.exe --repair-runtime` 可尝试修复运行时。

旧 Windows 0.5.0 有用户启动兼容反馈，且不包含本次离线修复与新诊断。历史文件保留供追溯，新的 Windows 下载请使用上表 0.10.2rc1。

### macOS 0.10.2 与 Windows 0.10.2rc1 的人格与整理

- 新库默认启用人格和学习，空白资料不会生成人格；用户明确关闭的选择继续保留。Windows 0.10.2rc1 已移植以上新默认与人格形成；Android／iPhone 0.8.0rc2 尚未移植。
- **强烈建议为当前库配置整理 API。** 在“记忆整理”设置模型与 Key，检查费用预算后按“保存并开启自动整理”；之后整理记忆时会在同一次调用中逐步补充人格。原文保存、检索、完整导出及手动设定无需模型 Key，连接 Agent 的配置仍无需模型厂商 Key。
- 导入明确标有 user／assistant 的旧聊天后，可用“快速整理人格”先预览范围、再确认最多一次模型调用。只根据可核验的助手原话归纳，不声称一次读完整库；学习结果独立展示，固定设定优先。
- 图主题只切换画布黑白，原像素界面、按钮和图标保持原配色；动态星云与平面引力图只使用已有星星按钮切换。Windows 实现和验收范围见 [本轮更新说明](WINDOWS-0102-UPDATE.md)；原 [0.10 交接书](https://github.com/myflww/love-house/blob/v0.10.0/docs/WINDOWS-010-HANDOFF.md) 保留作为同步依据。

升级前请停止写入并备份完整数据目录；本版整理数据库增加任务目的列，回退旧版时须同时恢复升级前的配套数据快照。

当前主程序未使用商业发行证书：macOS 为本地签名、未公证，Windows 未附发行商代码签名。请核对仓库来源与 SHA256，保留系统安全保护。随包微软运行时安装器的 Microsoft 签名与爱之屋主程序签名是两回事。

## 连接 Agent 的平台差异

Windows 可使用 Harness 专用连接器或通用 MCP 记忆连接。MCP 在线提供记忆工具，自动存档还需要宿主提交真实的轮次结束 Hook；仅复制 MCP 配置不代表自动记录已经验证。

macOS 0.10.2 与 Windows 0.10.2rc1 提供 AstrBot 实验来源的 `/sid` 配置引导，配置生成不会改写 AstrBot 安装目录，也不证明真实 QQ 已送达或已读。已有绑定须备份并合并，不能直接覆盖。服务器或隔离容器需在实际 AstrBot 能访问的文件系统生成配置，不能复用另一台电脑的绝对路径。详见 [AstrBot 0.3.0 插件](https://github.com/myflww/love-house/blob/v0.10.2/extensions/astrbot-love-house/README.md) 和 [同鱼多平台接入](https://github.com/myflww/love-house/blob/v0.10.2/docs/同鱼多平台接入.md)。

Windows 保留 Harness 检测与实际轮次验证；WorkBuddy 使用独立 MCP 配置流程。见 [WorkBuddy 接入说明](WORKBUDDY-CONNECTION.md)。不宣称能读取任意聊天客户端。

记忆连接本身不需要模型厂商 API Key。可选的整理模型、分享阅读索引或高级 API 转发由使用者单独配置。各系统继续使用 PolyForm Noncommercial 1.0.0，保留 myflww 署名及第三方许可。

Android 0.8.0rc2 原签名安装包、iPhone 主屏幕入口与升级说明见 [手机版安装与使用](手机版安装与使用.md)。本次 Windows 同步依据另一台设备的 [0.9.2 交接](https://github.com/myflww/love-house/blob/v0.9.2/docs/WINDOWS-092-HANDOFF.md)、[0.10 人格与原版星图交接](https://github.com/myflww/love-house/blob/v0.10.0/docs/WINDOWS-010-HANDOFF.md) 和 [0.10.1 独立记忆交接](https://github.com/myflww/love-house/blob/v0.10.1/docs/WINDOWS-0101-HANDOFF.md)，实现与 Windows 验收见 [0.10.2rc1 更新说明](WINDOWS-0102-UPDATE.md)。
