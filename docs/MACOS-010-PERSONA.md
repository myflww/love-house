# 爱之屋 macOS 0.10.0：人格与记忆一起生长

版本0.10.0，macOS构建15。承接0.9.2，合入人格形成和黑白神经星云。Windows与手机安装包仍按各自发布版本维护。

## 怎么使用

1. 选中她自己的存档。旧聊天可通过“导入聊天”导入明确标有user／assistant角色的记录；普通分享JSON也可以导入成独立新库。
2. 打开“连接运行程序 → 人格”。人格和“随对话学习”默认开启，没有资料时保持空白。用户明确关闭的设置不会被自动打开。
3. 强烈建议打开“整理 API 设置”，为当前库配置模型与Key，检查预算后点击“保存并开启自动整理”。这不是Agent聊天连接密钥，原文保存、检索与完整导出无需模型Key。
4. 积累或导入历史后，可点“快速整理人格”。先只读查看范围，再确认最多一次模型调用。每次按输入预算抽样，不声称已读完整历史；以后普通记忆整理会在同一次请求中继续补充，不另开人格专用付费调用。
5. 查看“从记忆形成”的特征及原话依据。可移除归纳错误的特征；明确指定的核心设定收在“固定设定”，优先保留。关闭学习停止新增；关闭人格也停止向Agent提供人格，资料仍保留。

## 底层边界

自动特征属于当前库，需至少两条独立、仍有效的本Agent助手原话。未知角色、工具输出、用户偏好、其他人的性格及未配对的代理建议不能冒充人格。已导入的旧system文字不会自动成为人格，明确设定仍由使用者导入或编辑。

同轮采集副本不算两条证据。单条整理频率可补充至多一条较早的有效助手原话，仅供人格依据使用；普通事实不能引用它。引用必须逐字对应当前节点，归档中未进入节点的续文不推断为人格依据。

来源被更正、停用、遗忘或改版后，相关特征暂停参与回忆；分享导入须按新库和当前来源重新核验，不能盲目信任旧缓存。学习结果不能覆盖手动设定、身份名、权限或安全规则。移除的相同特征会被阻止自动加回。

快速整理是独立目的任务，不会重放事实操作、清空或完成普通记忆队列。失败不会自动重试。调用沿用本库的次数、字符预算与持久账本；页面打开、只读预览和查看特征不调用模型。

普通整理的人格候选按项校验，非法人格不会连带丢掉已经通过校验的普通事实；全部候选非法时快速任务明确失败，没有候选时明确无新增，不把队列完成当作形成人格。诊断仅返回固定原因和计数，不包含模型原文。

人格模型规则独立版本化，普通事实规则保持兼容，旧的有效事实缓存不因增加人格功能再次付费调用。关闭、撤回和处理中更改设置有版本防护，不让迟到结果覆盖新选择。

## 验证与限制

已在独立临时库使用DeepSeek整理模型完成真实快速验收：从合成助手聊天形成2条特征，手动核心及普通队列保留，另一库为空；关闭人格／学习均阻止新请求。两次授权请求中第一次格式校验失败，修复后第二次通过；失败也计入调用账本，生产人格与原设置均未改动。普通批次的持续补充已以假传输验证，不冒充又一次真实模型验收。

原生WKWebView隔离自检已验证默认两个开关开启、空白手动设定收起、形成层优先、API提示、无Key只读预览、真实开关操作、切库独立及后端重启后关闭设置保留。图视觉直接采用已批准隔离版代码，10个绘制／布局函数按原文校验，主题只作用图画布；模式只用原有星星像素按钮切换，没有新增分段按钮。最终源码909项后端检查通过（1项外部AstrBot环境检查跳过），191项JS检查通过。新版0.10.0/build15已完成本机覆盖安装，原App与停止写入后的完整数据目录均已备份；现有库、回收站、连接有效范围、当前选库、整理设置和凭据元数据均保留，明确手动人格／学习选择也保留。仅旧的隐式空白关闭状态按新默认启用，没有凭空生成人格特征。公开安装包的SHA256与下载核验信息见同版本发行页附件。

源码测试与合成资料只证明对应流程；不等于所有模型、任意角色模糊的聊天文件或所有宿主均能自动形成人格。人格特征是有依据的角色归纳，不证明现实意识或情感。

## 升级与回退

记忆仍保存在原数据目录，模型Key不进入导出或人格。本版为organizer.sqlite3.jobs增加purpose列。升级前备份停止写入后的完整数据目录和原App；回退0.9.2时须同时恢复升级前的配套数据快照，不能只换回旧App继续写新数据库。
