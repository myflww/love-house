# 浏览知识星图

神经美术视图适配Digital Brain的MIT开源细丝与GLSL，使用本地打包的Three.js：半透明珠状神经元、带层次的弯曲细丝、低强度呼吸光。光脉冲沿实际关联召回的传播路径前进；没有查询时不会把随机光点冒称为正在思考。

分析视图保留Canvas2D绘制；WebGL不可用时自动降级。两个视图使用相同节点、连接、选择和相机状态。材质与布局不改变知识库逻辑。

- 神经美术视图：拖动画面旋转空间，Shift拖动平移；滚轮/双指缩放。
- 二维分析视图：拖空白平移；拖节点调整局部布局。
- 右侧加减按钮缩放，“适应所有节点”或键盘0回到全图。
- 缩略图点击或方向键导航；全屏按钮扩大观察区域。
- 搜索框输入即筛选节点列表；点列表或图中节点查看全文。
- 关联召回执行真实后端扩散；结果包括分数、跳数和来源路径。
- 聚焦邻居降低图的复杂度，“返回全图”恢复。
- 类型与状态按钮筛选；列表的“继续显示”可以浏览全部节点。
- 时间滑块只读；回到此刻才能新增/强化。
- 设置中控制标签、扩散参数和显式学习；暂停动效减少持续运动。

锚点详情显示保护原因、事件时间、会话与有限真实上下文。来源全文被遗忘后，保留下来的只是标注过的摘录，不能冒充完整回忆。

离线HTML支持浏览与文本匹配示意，不能保存、强化或调用后端规则做时间推演。数据来自导出时刻，打开快照不会同步写回原库。
