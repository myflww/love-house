# Windows 0.10.3rc1 更新与恢复说明

0.10.3rc1 提供完整安装版和便携版，整合整理恢复、多窗口并发、模型能力和星云交互。系统要求及其他平台版本见 [下载与系统支持](下载与系统支持.md)。

## 升级与数据保留

1. 停止爱之屋与向它写入的客户端，备份完整 `%LOCALAPPDATA%\LoveHouse` 数据目录；自定义目录按实际位置备份。
2. 从 [0.10.3rc1 发布页](https://github.com/myflww/love-house/releases/tag/v0.10.3rc1) 下载安装版或便携版，核对同版本 `Windows-SHA256SUMS.txt`。
3. 安装版覆盖原程序并保留数据目录；便携版完整解压到新程序目录后运行 `LoveHouse.exe`，继续使用原数据目录。
4. 核对原记忆库、窗口连接、人格与学习的明确开关、整理模型和密钥保存状态。AstrBot、Harness、WorkBuddy 继续按各自凭据、窗口与白名单核验。
5. 回退旧程序时，配套恢复升级前的数据快照。

微软 WebView2 与 .NET 继续沿用原有检查及诊断。需要诊断时运行 `LoveHouse.exe --diagnose`，日志只记录运行事实。

## 让失败记忆继续整理

选择目标库，打开“记忆整理”，确认 API、模型、凭据及启用开关。每日字符和次数上限已取消，近24小时数字仅作统计；旧配置上限不会继续卡住队列。

启用时普通旧失败任务自动重新排队，以5秒起、最长5分钟的间隔继续尝试。可点“立即整理”主动处理积压。配置或网络恢复后继续处理，无需删除原文或新建空库来清除失败数。核对待整理数量减少及完成数增加。

证据不足或矛盾的结果仍进入候选，交给用户审阅。已忘记、取消或完成的记录按原状态处理；单独确认的快速人格任务保留明确发起边界。

## 模型与推理强度

1. 选择“跟随当前库的接入模型”或“独立整理模型”，使用当前库所属的连接。
2. 点“读取可用模型”。独立模式查询填写的 API；连接模式使用真实连接的模型。该操作不发送记忆正文，不调用聊天模型。
3. 选择模型和推理强度。没有公布强度时，通用选项标注“需服务支持”；不确定时保留“自动 · 服务默认”。
4. 上下文与输出留空时使用模型最高能力，未知能力由服务决定；需要时手动填写 token 数后保存。保存 Key 后输入框清空，凭据保存范围单独显示。
5. 核对一批实际整理结果。API 明确超窗或截断时自动缩片，未完成进度保留；厂商权限、余额及兼容性问题按提示修复。

## 多窗口同时使用

每个窗口先由用户明确连接到目标存档。多个已连接窗口可同时导入与召回，同一事件重复交付按回执去重。默认单窗口、显式整个连接范围、来源白名单和不同记忆库权限继续保留。

分别完成一轮测试对话，核对各自原文入库和召回，再从未连接窗口核对拒收。配置生成、工具在线、实际归档及实际返回资料分别确认。切换星图浏览的库不会改写已有连接。

## 星云与版本提醒

普通拖动旋转，Shift 拖动平移；失焦或丢失指针后取消旧手势。悬停与空白点击继续自旋，拖动松开恢复；选中节点或明确暂停时停止。滚轮、双指缩放及平面图继续保留。

设置里可选择自动检查与发布通道。开启时每次打开检查当前系统新版，有更新时弹窗显示版本、说明与可信下载入口，同次运行同版本不重复提醒。点“稍后”或“关闭”继续使用；已有对话框完成后再提醒。离线、无新版或关闭自动检查时不弹出。
