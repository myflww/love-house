## Windows 安装

1. 优先下载安装版 EXE，按当前用户安装。桌面包自带所需程序，无需另装 Python 或 Node。
2. 启动需要 Microsoft WebView2 Runtime 和 .NET Framework 4.6.2+。缺少 WebView2 时，程序会询问是否安装随包的微软离线组件，并核对其签名和 SHA256；该组件不包含 .NET 安装器。
3. 使用便携版时，完整解压整个文件夹，再打开 `LoveHouse.exe`。
4. 本机记忆保存在 `%LOCALAPPDATA%\LoveHouse`，与程序目录分开。请勿通过清空数据目录处理启动失败。
5. 启动异常时可运行 `LoveHouse.exe --diagnose`，按提示查看诊断；明确执行 `LoveHouse.exe --repair-runtime` 可尝试修复运行时。

Windows 的构建、安装、覆盖升级、原生运行及公开下载复核以 [0.10.7rc1 发布说明](release-0.10.7rc1.md#验证与下载)和同页验证附件为准。Windows 10/11 是支持目标，不表示全部系统已实测；受限安装和缺失/损坏运行时环境仍需分别验收。

## 桌面 0.10.7rc1 的整理与连接

新版按所需公开接口检查 DSH 兼容性，升级时刷新已有且归属可核对的适配器副本。保留连接身份、库与窗口范围及暂停状态；已经运行的 DSH 需要重新加载插件一次，以真实轮次回执确认存档。

取消每日调用、字符及待审候选总量硬上限；普通失败任务持续退避重试，旧版停住的任务会重新排队。原文保存、已有淡忘规则、候选审阅和真正忘记的选择继续保留。多个已授权窗口可同时导入与召回，每条连接仍固定记忆库及用户批准的范围。

整理模型可读取可用列表并选择推理强度；上下文与输出默认所选模型最高，未知能力由服务决定。星云普通拖动旋转，Shift 平移；悬停和空白点击继续自旋，选中节点或明确暂停才保持停止。自动检查开启时，打开软件会检查当前平台新版并弹窗提醒，下载与安装由用户选择。

当前版围绕真实话题检索已保存的材料，不把“刚才那个”等无对象套话单独当作相关性。可以读取当前、历史及前后比较；更正保留原话，停用与真正忘记按用户选择生效。空闲整理默认关闭，只在本地维护原文目录和同会话前后文，不调用模型，也不再生成反思、策略或模拟提案。

Windows 和 macOS arm64 同步共享记忆核心，各自的原生构建与运行记录见[本版说明](release-0.10.7rc1.md)。Android 的本机功能与服务连接范围见[手机版安装与使用](手机版安装与使用.md)。源码测试不代表未验证平台的兼容性。

## macOS 安装

下载并解压 ZIP，把“爱之屋.app”放入“应用程序”目录后打开。当前安装包仅适用于 M 系列芯片的 Mac。

macOS 包为本地签名、未公证；Windows 主程序未附发行商代码签名。请核对仓库来源和下方 SHA256，保留系统安全保护。随包微软运行时的数字签名不代表爱之屋主程序已有发行商签名。

## Android 安装

0.10.7rc1 源码和构建已同步，原签名设备按[交接书](ANDROID-0107-HANDOFF.md)完成签名和升级验收后追加新版 APK；在此之前当前可安装版仍为 0.10.6rc1。

Android 下载 APK 后，按系统提示允许当前下载来源安装，再打开“爱之屋”。本 APK 同时包含 arm64-v8a 与 x86_64；32 位系统不支持。只使用上表的发行包，开发流水线中的 unsigned APK 和测试 APK 不用于日常安装。

0.10.6rc1 使用原持久发行签名，包名不变，可直接覆盖安装 0.8.0rc2；先逐库导出 JSON，保留旧 App 与数据，不要先卸载。新版内置 Python 和共享记忆核心，无需另装 Python。详见 [Android 升级与验证范围](ANDROID-0106-UPDATE.md)。

原发行签名已核对；公开旧版 0.8.0rc2 → 本版的双库覆盖升级及进程重启通过。Android 16 / API36 的完整引擎 11 项测试及额外迁移、幂等、实际文件导出恢复、库隔离与凭据重启验收通过；Android 9 / API28 的旧内核仅通过旧入口、内核更新提示 7 项及旧库升级保留，不代表完整引擎可在该旧内核运行。完整界面需要 WebView 109+。以上为独立模拟器与合成数据，未调用付费模型，实体手机尚待验证。

新版将本机完整记忆引擎与旧版离线库分开保留；旧库由用户明确点击迁移，不会删除原数据。新增网络权限用于本机引擎、更新检查和所选模型 API，不会自动收集其他 App 的聊天或操作。手机上的 `127.0.0.1` 无法连接电脑或云服务器里的 Agent；需要使用远端设备运行的爱之屋 HTTPS 服务。关闭完整记忆界面后不保证持续运行，系统省电或结束进程可能停止手机接收。

Android 的真实手机兼容性仍待验收。连接个人 HTTPS 记忆服务时，对应电脑或服务器需要在线。各设备存档不会自动云同步。

旧 iPhone 版已停止提供。已有本机记忆的迁移步骤见[手机版安装与使用](手机版安装与使用.md#旧-iphone-版的记忆迁移)，不要通过删除旧应用或清除网站数据来迁移。

## 升级与备份

- 升级前停止写入，导出 JSON，并备份完整数据目录。桌面版回退时，应同时恢复升级前的配套数据快照。
- Windows 安装版覆盖安装；便携版完整解压到新程序目录，保留原来的数据目录。不要把程序目录当作记忆备份。
- Android 旧版用户先备份，再直接覆盖安装原签名 APK；不要先卸载。卸载后重装不属于覆盖升级。
- 卸载 Android、清除应用数据、清除网站数据或系统回收网页存储，都可能删除手机本机记忆。请定期导出 JSON。
- 设备之间没有自动同步。迁移使用 JSON；Markdown 用于阅读。
